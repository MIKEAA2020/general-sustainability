# 3. Issue-by-issue provisional answers

## A1 — Article 001 robust tangency versus strong invariance

**Verdict:** `PROOF_INCOMPLETE`.

### Corrected statement

Let \(K\) be closed. Suppose a measurable feedback \(k\) satisfies

\[
F_k(x)
:=
\{f(x,k(x),d):d\in D(x)\}
\subseteq T_K(x)
\qquad\forall x\in K.
\]

Assume the closed-loop inclusion has complete solutions, and impose the regularity conditions of a strong-invariance theorem—for example upper semicontinuity, compact convex values, suitable local boundedness/Lipschitz conditions, and the appropriate tangent condition. Then every solution of the closed-loop disturbance inclusion remains in \(K\); hence the same feedback is robust against every admissible disturbance selection.

### Decisive distinction

The weak viability condition

\[
F_k(x)\cap T_K(x)\ne\varnothing
\]

only supports existence of a viable inclusion trajectory. Robust disturbance safety needs

\[
F_k(x)\subseteq T_K(x).
\]

### Counterexample under weaker condition

At a boundary point let \(F_k(x)\) contain one inward and one outward velocity. The intersection condition holds, but a disturbance selecting the outward velocity causes exit.

### Recommended status

Conditional theorem under a cited strong-invariance/discriminating-kernel result.

### Downstream effect

Article 001’s robust kernel and barrier claims remain usable after replacing the theorem and proof. Any result requiring only controlled existential viability can use the weaker condition.

## A2 — Order-minimal control principle

**Verdict:** `NOT_AN_ERROR_BUT_NEEDS_CLARIFICATION` for the theorem; the proof sentence is false.

### Corrected statement

If lower harvest is order-better in the resource/sink order, then the minimum-harvest trajectory dominates every admissible trajectory from the same state. Therefore:

\[
x_0\in\operatorname{Viab}(\mathcal V)
\iff
\text{the minimum-harvest trajectory from }x_0
\text{ remains in }\mathcal V.
\]

### Proof sketch

- If the minimum-harvest path remains safe, it is an admissible witnessing policy.
- If it exits, every other path is order-worse; because the safe set is an order-upper set, no other path can remain safe.

Do not claim every higher-harvest trajectory remains safe when the minimum path does.

### Status

Theorem after wording correction.

## A4 — Capital kernel with consumption floor

**Verdict:** `FALSE_AS_STATED` only for the claim about all larger consumption.

### Correct theorem

For

\[
\dot A=\Phi(A)-c,
\qquad c\ge c_{min},
\]

if the controller may choose \(c=c_{min}\) and \(\Phi\) is continuous/concave with a nonempty superlevel set

\[
\{A:\Phi(A)\ge c_{min}\},
\]

then the viability kernel is \([A_-,\infty)\) under the stated one-dimensional shape assumptions. The witnessing policy is \(c=c_{min}\).

Higher consumption is not guaranteed safe.

### Counterexample

Choose \(c\) arbitrarily large. Then \(\dot A\) is negative at the boundary and the state exits.

## C1 — Epistemic fixed-point operator

**Verdict:** `FALSE_AS_STATED` in Article 006.

### Preferred repair

Use a safe base set \(S_{safe}\) and

\[
\Phi(Q)=S_{safe}\cap Pre(Q),
\qquad
K_0=S_{safe},
\qquad
K_{n+1}=\Phi(K_n).
\]

This matches ordinary safety-game predecessor iteration.

### Countable limit

If the iterates are nested compact sets, action sets are compact, transition/update graphs are closed, and predecessor is continuous from above, then

\[
K_\infty=\bigcap_nK_n
\]

is a fixed point. Nested compact witnessing-action sets can preserve a common limiting action. Without such continuity/compactness, Tarski guarantees a greatest fixed point on the complete lattice, but transfinite iteration may be required.

The alternative contracting operator \(Q\cap Pre(Q)\) is possible but less clean if \(Pre\) already enforces current safety.

## 4.2 Distributive operationalization

### Exact margins

For each component:

\[
m_k=(a_k-a_{floor,k})/s_k
\]

with positive units-matching scale \(s_k\). Exact conjunction is

\[
\min_km_k\ge0.
\]

### Smooth certificate

\[
h_\rho
=-\rho^{-1}\log\sum_ke^{-\rho m_k}
\]

is conservative:

\[
h_\rho\ge0
\Rightarrow
\min_km_k\ge0.
\]

Use the \(\log n/\rho\) approximation error explicitly.

### Population criterion

Use a declared quantile, expected shortfall, or essential infimum. For global pooling, construct the mixture CDF before taking the quantile.

### Dynamic result

Only after specifying dynamics and policy classes should a barrier/viability condition be imposed. Floors remain normative inputs with provenance and uncertainty.

# 5. Restricted transformation theorem target

## Proposed first theorem class

Use a finite architecture graph \(Q\). For each mode \(q\):

- compact state space \(Z_q\);
- closed safe set \(K_q\);
- compact action/disturbance sets;
- continuous sampled transition \(F_q\);
- robust viability kernel \(V_q\).

For edge \(q\to q'\):

- closed transition guard \(G_{qq'}\);
- continuous reset \(R_{qq'}:G_{qq'}\to Z_{q'}\);
- transition cost/harm bound;
- identity/obligation compatibility condition.

Augment the system with mode \(q\). Define target

\[
\mathcal T
=
\bigcup_q\{q\}\times V_q.
\]

Then compute a robust reach–avoid capture basin in the disjoint-union hybrid state space. Under compactness and continuity, sampled predecessor iteration gives a largest set from which one meta-policy avoids forbidden states and reaches \(\mathcal T\).

### Why nontrivial

The target kernels are endogenous architecture-specific invariant sets, and resets must preserve translated obligations. A second theorem can compare this hybrid capture basin with the union of within-architecture kernels.

### Limitation

This is a finite sampled theorem, not a general continuous-time category of arbitrary architectures.

# 6. Restricted composition theorem target

## Proposed class

Barrier-certified subsystems

\[
\dot x_i=f_i(x_i,u_i,z_i),
\qquad z_i=C_i(x_{-i}),
\]

with safe sets \(K_i=\{b_i\ge0\}\).

Suppose each subsystem has an interface tolerance \(\bar z_i\) and a local policy satisfying

\[
\inf_{d_i}
D^+b_i(x_i;f_i(x_i,u_i,z_i,d_i))
\ge0
\]

on \(\partial K_i\) whenever \(\|z_i\|\le\bar z_i\). If

\[
\sup_{x\in\prod K_j}\|C_i(x_{-i})\|
\le\bar z_i
\]

for every \(i\), controls are jointly feasible, and event/reset composition preserves the product set, then \(\prod_iK_i\) is robustly invariant.

This is essentially Article 001’s restricted theorem and should be the first proved compositional result. Later replace fixed tolerances by gain functions and a small-gain condition.

### Counterexamples to retain

- coupling destroys factorwise viability at asymmetric MSY;
- coupling rescues a patch that is nonviable in isolation;
- shared controls can make individually feasible contracts jointly infeasible.
