# Self-Contained General-Theory Mathematical Closure Packet

## Purpose

This packet supports rigorous external or internal work on the **major mathematical obstacles to a coherent general theory of sustainability**. It deliberately excludes narrow numerical certification tasks such as individual fold certificates, branch continuation, or unfinished interval computations.

## Controlling objects

1. `TCS-1.0` is the canonical typed system/theorem schema.
2. Immutable A001/A002 sources are included for exact proof checking.
3. Corrected theorem records supersede defective source formulations without editing source files.
4. Concordances and locators prevent content loss and status promotion.

## Major open targets

1. Strengthen Operator II beyond standard backward reachability through a genuinely typed transformation/impossibility result.
2. Prove the observation → assessment → prescription → implementation bridge.
3. Prove when viability judgments imply, bound, or fail to imply empirical diagnostics.
4. Give a general domain-admission/projectability theorem with explicit approximation and safety erosion.
5. Extend restricted composition only where a true assume–guarantee or nonlinear small-gain theorem is possible.
6. Close cross-scale aggregation without treating static identities as dynamic closures.
7. Formalize intergenerational and architecture-changing continuation sets.
8. State the robust/epistemic/chance hierarchy with exact law/support and information assumptions.
9. Establish one complete typed application mapping; empirical calibration itself is outside this mathematical packet.

## Excluded priorities

- fold/SNPO certification;
- individual branch-continuation refinements;
- A021 numerical orbit or Floquet certification;
- venue selection and manuscript formatting;
- unverified empirical calibration.

## How to use

Start with `10_MASTER_REVIEW_PROMPT.md`, then use `11_OPEN_THEOREM_DOCKET.md`. Every proposed theorem must be returned using `12_REQUIRED_OUTPUT_SCHEMA.md`. Source-level claims must cite the included source file and exact line/theorem label.
