# Required Output Schema for Every Proposed Closure Result

1. **Result ID and target docket item.**
2. **Verdict:** proved / repairable / false / classical / conjectural.
3. **Exact statement.**
4. **State and phase space.**
5. **Quantifier order and information pattern.**
6. **Assumptions, including existence/completeness.**
7. **Mapping type:** exact specialization / embedding / projectable reduction / transformation / approximation / limit / rejected mapping.
8. **Self-contained proof or clause-level theorem match.**
9. **Counterexample showing necessity or failure outside scope.**
10. **Interface producer/consumer contract.**
11. **Error, horizon, and safety erosion for approximations.**
12. **Selector and implementation regularity.**
13. **Stochastic/hybrid/RFDE qualifications.**
14. **Novelty status with exact references.**
15. **Publication destination.**
16. **Remaining obligations and revocation triggers.**
17. **Machine-readable dependency edges.**
