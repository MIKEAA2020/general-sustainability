# 1. Audit method

## 1.1 Evidentiary treatment

ER001–ER005 remain five reviewer units. ER004’s coordinated six-file package counts once. ER005’s identical `2.txt` and `3.txt` count once. ER003’s pasted and uploaded versions count once.

The earlier phrase that reviewer units were “weighted equally” is imprecise. The correct rule is:

> No reviewer receives recency, file-count, confidence-label, or identity privilege. Each distinct argument is assessed on mathematical and evidentiary merit. Agreement is corroboration, not a vote or a numerical weight.

## 1.2 Recommendation reconciliation classes

The companion CSV uses these dispositions:

- **RATIFY_COMPLETED** — completed work remains valid and is not reopened.
- **RATIFY** — the existing decision remains controlling.
- **RETAIN_PENDING** — valid pending work, still unimplemented.
- **RETAIN_BLOCKED** — valid implementation task whose prerequisites remain unresolved.
- **RETAIN_CONDITIONAL** — useful only for unique-content extraction, a supplement, or deliberate source revival.
- **RETAIN_PRIMARY_CASE** — retained because it supports the conditional groundwater-first case.
- **RETAIN_REDESIGN** — retained only as a clean redesign, not a repair validating a rejected source.
- **MODIFY** — the recommendation survives only in the corrected form stated here and in the row-level reason.
- **SUPERSEDE** — a later joint decision replaces it.
- **DORMANT_REJECTED_BRANCH** — do not execute unless the rejected branch is deliberately rebuilt.
- **DEFER_OPTIONAL** — legitimate but outside the present load-bearing sequence.

No row is silently discarded.

# 4. Mathematical decisions that control the backlog

## 4.1 Viability and invariance hierarchy

All relevant actions must distinguish:

- controlled existential viability;
- robust/discriminating viability with explicit quantifier/strategy order;
- fixed-policy robust safety;
- strong invariance of an inclusion;
- epistemic viability on an information/history state space;
- institutionally implementable viability;
- chance viability under a law and filtration;
- capture/recovery relative to target, envelope, horizon, policy, and disturbance classes.

A1 is repaired only by a theorem whose regularity and solution assumptions match the claim. The immediate safe form is conditional sufficiency. A broad pointwise-tangency iff is not adopted.

## 4.2 A001 docket

The A001 action cluster is retained with these controlling dispositions:

- **A1:** conditional strong-invariance or discriminating-kernel repair;
- **A2:** existential minimum-control witness, not all-control safety;
- **A3:** correct comparison sign and retain the inner bound only with complete comparison and sink-invariance assumptions;

- **A10:** use Ostrom principles as mechanism mappings, not universal necessary conditions;
- **A11:** existential viability is upward-monotone in action-set inclusion; universal-action safety is a different object.

## 4.3 A002 and selector/application obligations

A002 remains canonical, but its backlog must preserve four levels:

1. pointwise saving-action nonemptiness;
2. measurable selector under an appropriate selection theorem;
3. continuous selector only under stronger hypotheses;
4. closed-loop implementability and a declared solution semantics.

Exact filters, exact tubes, compactness, and Hausdorff continuity remain assumptions until an application constructs or safely approximates them. Each application bridge must state approximation error and safety erosion.

## 4.4 Epistemic fixed point

The official operator is

\[
\Phi(Q)=S_{safe}\cap Pre(Q),\qquad Q_0=S_{safe}.
\]

The deflationary form `Q ∩ Pre(Q)` is not rejected as nonmonotone. It may be retained only after proving orbit equivalence for the chosen initialization. Countable descent requires finite-state or compact/closed continuity-from-above conditions; otherwise transfinite iteration may be required. No unsupported exact ordinal bound is adopted.

## 4.5 Hybrid/history typing

Use `(x_t,q)` or a proper hybrid/càdlàg phase space. RFDE kernels live in history spaces, not ordinary physical state spaces. A latent mode appears once inside a joint belief; an observed mode appears once as a known coordinate. Full reset, continuation, event priority, and non-Zeno semantics are required before theorem use.

## 4.6 A011–A013

- **A011:** zero-order hold is official; interpolation is a separate theorem/model class. Retrospective evidence retains its registered reproducibility status; prospective causal work remains prospective.
- **A012:** numerical truth remains accepted at exact source-stated status. Apply the extinction-face equilibrium, stock-culling stopping/donor limit, notation, MPF-simplex, and status-preservation corrections. Publication archiving is not a truth-verification gate.
- **A013:** values remain accepted as verified. Rename the service readout. Separate ray attainment from radial interval feasibility as described in §2.2.

## 5.2 Composition

The first theorem should establish bounded-interface robust invariance with:

- local robust certificates;
- verified interface bounds on the proposed joint set;
- jointly feasible shared controls;
- compatible disturbance semantics;
- nonblocking event/reset composition.

Required examples remain:

1. coupling destroys local viability;
