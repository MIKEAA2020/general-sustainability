# Required Output Schema

1. Task ID and dependency gates.
2. Exact model/version/hash.
3. Mathematical object being certified.
4. Phase/state/history space and norms.
5. Input artifacts and hashes.
6. Software/environment and outward-rounding method.
7. Algorithm and theorem used.
8. Finite-dimensional bounds.
9. Infinite-tail/continuum bounds.
10. Residual, inverse, derivative, and radii/Krawczyk data.
11. Spectral/projection/nondegeneracy data where relevant.
12. Reproduction command and expected outputs.
13. Machine-readable certificate paths.
14. Failure modes and sensitivity checks.
15. Exact claim status before and after.
16. Promotion decision and remaining blockers.
17. Independent-rerun record.
