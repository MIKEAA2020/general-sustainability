# Self-Containment Audit — A018-to-A021 Crosswalk Prompt

## Verdict

The prompt was **not fully self-contained in the strict evidentiary sense**. It was self-contained as a task specification and included the principal C3 equations, candidate list, safeguards, and required outputs, but it remained dependent on a source packet for the evidence needed to complete the task.

## Packet-dependent content omitted from the prompt

1. Full C4 definitions of `R(N,A)`, `B(N,A)`, the dynamic target, and closure scope.
2. Full C5 equations and the exact driven/nonfeedback status of `U` under each closure.
3. Complete Candidate-A/B parameter and unit tables.
4. Exact C4 equilibrium and characteristic matrices.
5. Exact branch identities, periods, amplitudes, and all source-stated Floquet evidence.
6. Exact A021 original and corrected passages defining the norm, block split, and coupling status.
7. Exact source line/label excerpts needed for a provenance table.
8. The actual BLZ theorem text; the prompt provided bibliography and required the reviewer to open it.

## Consequence

A reviewer without workspace/file access could responsibly return only an access-limited partial audit, as ER020 did. Its inability to provide exact labels was caused by prompt design, not by absence of those files in the workspace.

## Required correction for a strict self-contained version

A revised prompt must embed a source dossier containing all relevant equations, parameter tables, source labels, characteristic/Floquet statements, A021 coupling passages, and either the exact external theorem text or a clearly bounded theorem-verification task with web/source access. It must distinguish quoted source facts from instructions and identify any material intentionally omitted.

No revised prompt is issued during the announced multi-audit intake unless authorized or after the audits are jointly adjudicated.
