# JIE revision v2

This is a new, non-overwriting revision of the Journal of Industrial Ecology submission package. The earlier v1 files remain separate; this directory contains the v2 sources, PDFs, cover letter and validation records.

- `paper3_JIE_submission_v2.md` and `rendered/paper3_JIE_submission_v2.tex` are synchronized article sources.
- `rendered/paper3_JIE_submission_v2.pdf` is the rebuilt main article.
- `paper3_JIE_supplement_v2.tex`, its PDF and log are the separate supplementary material.
- `cover_letter_JIE_v2.md` and `rendered/JIE_cover_letter_v2.pdf` are the cover letter and compiled PDF.
- `assets/typed_ledger_readout.svg` and `.png` are the Figure 1 assets.
- `audit/JIE_LINE_REVIEW_v2.*`, `journal_variants_v2_validation.json`, `CHECKSUMS.sha256` and `paper3_JIE_supplement_v2_validation.md` record the v2 checks.

The abstract is self-contained. The author metadata uses visible hyperlinks for the ORCID and email. The CRediT statement contains only the contribution statement. The main body remains below 6,000 words; the supplementary material is separate.

The linked public records are:

- Main article: [10.6084/m9.figshare.33942451](https://doi.org/10.6084/m9.figshare.33942451)
- Methods paper: [10.6084/m9.figshare.33942469](https://doi.org/10.6084/m9.figshare.33942469)
- Accounting-standards paper: [10.6084/m9.figshare.33942487](https://doi.org/10.6084/m9.figshare.33942487)

The expanded local package is not represented as an externally uploaded or newly assigned DOI record.
