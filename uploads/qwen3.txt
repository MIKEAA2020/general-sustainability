Proceeding with **1: drafting a restricted but nontrivial Operator II transformation theorem**.

Below is a draft canonical formulation intended to fit the master manuscript’s Operator II and the review packet’s Priority 3. It is deliberately restricted to a class where a clean theorem can be proved, while preserving the essential sustainability content: architecture change, identity continuity, forbidden/irreversible states, cumulative harm, translation of obligations, and destination viability.

---

# Operator II: Restricted Transformation Theorem

## 1. Purpose

Operator I asks:

\[
z_0 \in \operatorname{RViab}_{\mathcal A_q}(K_q,T)
\]

meaning: from the actual initial state, one implementable causal policy can keep the system inside the typed safe set under the declared disturbance class.

Operator II asks a different question:

> If the current architecture cannot maintain the full typed judgment, can the system transform through a registered sequence of architectures to another architecture in which robust viability can be reached and maintained, without violating identity continuity, non-relaxable constraints, cumulative-harm budgets, or irreversibility constraints?

The draft theorem below gives a precise, restricted answer.

---

## 2. Canonical notation for Operator II

To avoid collisions with existing notation, I recommend the following.

| Symbol | Meaning |
|---|---|
| \(\mathcal G_A=(Q,E_A)\) | finite architecture graph |
| \(q,q'\in Q\) | architecture indices |
| \(Z_q\) | state space of architecture \(q\) |
| \(\Lambda\) | cumulative harm/burden/liability state |
| \(Y_q=Z_q\times\Lambda\) | augmented architecture state |
| \(\mathsf A_q\subseteq Y_q\) | compact transition-admissible region in architecture \(q\) |
| \(F_{\mathrm{forbid}}\) | forbidden/irreversible region, encoded by exclusion from \(\mathsf A_q\) |
| \(U_q\) | within-architecture action space |
| \(V_e\) | transition action space for architecture edge \(e\) |
| \(W_q\) | within-architecture disturbance set |
| \(W_e\) | transition disturbance set for edge \(e\) |
| \(f_q\) | within-architecture review-step map |
| \(r_e\) | reset/translation map for architecture transition \(e\) |
| \(\Theta\) | target set: destination Operator I viability kernels |
| \(\mathsf T^{II}_N\) | finite-horizon transformation basin |
| \(\ell\in\Lambda\) | cumulative harm/liability vector |
| \(\bar\ell\) | cumulative harm budget vector |
| \(\mathsf{Id}_e\) | identity-continuity predicate for transition \(e\) |

This avoids using \(K\) for both constraint set, sink burden, carrying capacity, and kernel. The safe/constraint sets remain \(K_q\), \(K_q^*\), etc., while the Operator II admissible region is written \(\mathsf A_q\).

---

## 3. Architecture graph and hybrid transformation state

Let

\[
\mathcal G_A=(Q,E_A)
\]

be a finite directed graph of registered architectures. An edge

\[
e=(q,q')\in E_A
\]

represents an authorized possible transformation from architecture \(q\) to architecture \(q'\).

Each architecture \(q\) has an augmented state

\[
y_q=(z_q,\ell)\in Y_q=Z_q\times\Lambda,
\]

where:

- \(z_q\) contains the physical, functional, institutional, informational, obligation, and liability coordinates relevant to architecture \(q\);
- \(\ell=(\ell_g)_{g\in G}\) records cumulative harms, burdens, transition debts, or stranded liabilities for protected groups or systems \(g\);
- \(\Lambda=\prod_g[0,\bar\ell_g]\) is compact.

The full hybrid state is

\[
y=(q,y_q)=(q,z_q,\ell).
\]

The architecture state space is the disjoint union

\[
\mathsf Y=\bigsqcup_{q\in Q}\{q\}\times Y_q.
\]

---

## 4. Admissible transition region, forbidden states, and constraints

For each architecture \(q\), let

\[
\mathsf A_q\subseteq Y_q
\]

be a non-empty compact set encoding:

1. non-relaxable physical, functional, normative, and relational constraints;
2. authorized temporary transition relaxations, if any;
3. cumulative-harm budgets \(\ell_g\le \bar\ell_g\);
4. exclusion of forbidden states \(F_{\mathrm{forbid}}\);
5. exclusion of irreversible states \(F_{\mathrm{irr}}\);
6. identity-precondition requirements needed before a transition may be attempted.

Thus, instead of writing

\[
y\notin F_{\mathrm{forbid}},
\]

as a separate condition inside the theorem, we encode it by requiring

\[
y\in \mathsf A_q.
\]

This is a clean topological assumption: the admissible region is compact and already excludes prohibited states.

If one wants explicit forbidden sets, one may write

\[
\mathsf A_q
=
\widetilde K_q^{\mathrm{tr}}
\cap
\{\ell\le \bar\ell\}
\cap
F_{\mathrm{forbid},q}^{c},
\]

but then one must assume that this set is closed/compact, or replace the forbidden set by a closed safety-margin buffer. For the restricted theorem, I recommend taking \(\mathsf A_q\) as primitive and compact.

---

## 5. Within-architecture dynamics

We state the theorem first in a review-synchronized sampled form. This is the cleanest version and connects directly to the Article 002 sampled/kernel machinery.

For each architecture \(q\), let:

- \(U_q\) be a compact within-architecture action space;
- \(W_q\) be a compact within-architecture disturbance set;
- \(f_q:\mathsf A_q\times U_q\times W_q\to Y_q\) be a continuous one-review-step map.

The map \(f_q\) includes the effect of:

- physical dynamics;
- capacity dynamics;
- obligation/liability updates;
- cumulative-harm accumulation;
- information/assessment updates if they are represented as state coordinates;
- authorized temporary constraint relaxation and transition debt.

A within-architecture step is admissible only if

\[
f_q(y_q,u,w)\in \mathsf A_q.
\]

If inter-sample continuous-time safety is required, \(f_q\) should be replaced by an exact tube/endpoint map as in Article 002. The restricted theorem can be extended to that case if the exact tube and endpoint maps are Hausdorff-continuous. Outer semicontinuity alone is insufficient.

---

## 6. Architecture transitions

For each edge

\[
e=(q,q')\in E_A,
\]

assume:

1. a compact transition action space \(V_e\);
2. a compact transition disturbance space \(W_e\);
3. a closed transition guard

\[
\mathsf G_e\subseteq \mathsf A_q;
\]

4. a continuous reset/translation map

\[
r_e:\mathsf G_e\times V_e\times W_e\to Y_{q'}.
\]

The guard \(\mathsf G_e\) encodes:

- authorization of the transition under \(\mathcal N\);
- identity-precondition satisfaction;
- minimum readiness conditions;
- absence of prohibited immediate harms;
- availability of translation maps for stocks, liabilities, obligations, beliefs, and institutional modes.

The reset/translation map \(r_e\) translates:

- physical stocks;
- capacities;
- liabilities and deferred harms;
- obligations and entitlements;
- institutional modes;
- information or belief coordinates, if represented;
- protected lower-level identity realizations;
- cumulative harm coordinates.

The identity-continuity condition is represented by a closed predicate

\[
\mathsf{Id}_e(y_q,r_e(y_q,v,w))=1.
\]

For simplicity, assume that this predicate is already enforced by the guard and reset map: if identity continuity fails, the transition is not admissible.

An architecture transition is admissible only if

\[
r_e(y_q,v,w)\in \mathsf A_{q'}.
\]

The robust quantifier is:

\[
\exists v\in V_e\quad \forall w\in W_e.
\]

That is, the meta-policy must choose the transition action before the transition disturbance is realized.

---

## 7. Destination target set from Operator I

Let \(Q_T\subseteq Q\) be the set of registered destination architectures.

For each \(q\in Q_T\), let

\[
\operatorname{RViab}_{\mathcal A_q}(K_q^*,T_q')
\subseteq Z_q
\]

be the Operator I robust viability kernel of architecture \(q\), evaluated over destination horizon \(T_q'\). This horizon may be finite or infinite.

Define the destination target set

\[
\Theta
=
\bigcup_{q\in Q_T}
\left\{
(q,z,\ell)\in \{q\}\times \mathsf A_q
:
z\in
\operatorname{RViab}_{\mathcal A_q}(K_q^*,T_q')
\right\}.
\]

Thus \(\Theta\) is the set of hybrid states that have already reached an architecture and state from which destination viability can be maintained.

Assume:

\[
\Theta
\]

is compact. This holds if each destination kernel is compact and the harm-budget coordinates are compact.

If \(\Theta=\varnothing\), no registered destination is viable and the transformation basin is empty.

---

## 8. Meta-policies and disturbance strategies

A meta-policy

\[
\Pi\in\mathbb P^{\mathrm{meta}}
\]

chooses, at each review decision:

1. whether to remain in the current architecture or attempt an authorized transition;
2. which within-architecture action or transition action to use;
3. how to respond to the observed hybrid state.

A disturbance strategy

\[
\delta\in\Delta^{II}
\]

selects admissible within-architecture disturbances and transition disturbances nonanticipatively.

In the full-state sampled version of the theorem, it is enough to use state-feedback meta-policies:

\[
\Pi(y)\in U_q
\]

or

\[
\Pi(y)=(e,v)
\]

for an available edge \(e=(q,q')\).

The quantifier structure is:

\[
\exists \Pi\in\mathbb P^{\mathrm{meta}}
\quad
\forall \delta\in\Delta^{II}.
\]

This is the Operator II analogue of robust viability.

---

## 9. Finite-horizon transformability

Fix a finite decision horizon \(N\in\mathbb N\). This counts the number of review decisions allowed before reaching \(\Theta\).

Define the backward transformation operator \(\mathsf B\) on subsets \(C\subseteq \mathsf A\) as follows.

Let

\[
\mathsf A=\bigsqcup_{q\in Q}\{q\}\times \mathsf A_q.
\]

For \(C\subseteq \mathsf A\), define \(y=(q,y_q)\in \mathsf B(C)\) iff \(y\in\mathsf A_q\) and at least one of the following holds.

### 9.1 Already at target

\[
y\in C.
\]

### 9.2 Within-architecture progress

There exists \(u\in U_q\) such that

\[
\forall w\in W_q,
\qquad
f_q(y_q,u,w)\in C.
\]

### 9.3 Architecture-transition progress

There exists an edge \(e=(q,q')\in E_A\) and an action \(v\in V_e\) such that

\[
y_q\in \mathsf G_e
\]

and

\[
\forall w\in W_e,
\qquad
r_e(y_q,v,w)\in C.
\]

Now define

\[
\mathsf T^{II}_0=\Theta,
\]

and

\[
\mathsf T^{II}_{n+1}
=
\mathsf B(\mathsf T^{II}_n).
\]

The finite-horizon transformation basin is

\[
\mathsf T^{II}_N.
\]

A hybrid state \(y=(q,z,\ell)\) is \(N\)-step transformationally viable if

\[
y\in \mathsf T^{II}_N.
\]

# 10. Restricted Operator II Transformation Theorem

## Theorem: finite-horizon robust architecture transformation

Assume:

1. \(Q\) and \(E_A\) are finite.
2. Each \(\mathsf A_q\) is compact.
3. Each \(U_q\), \(V_e\), \(W_q\), and \(W_e\) is compact metric.
4. Each within-architecture step map

\[
f_q:\mathsf A_q\times U_q\times W_q\to Y_q
\]

is continuous.
5. Each transition guard \(\mathsf G_e\) is closed in \(\mathsf A_q\).
6. Each reset/translation map

\[
r_e:\mathsf G_e\times V_e\times W_e\to Y_{q'}
\]

is continuous.
7. Identity continuity, obligation translation, and cumulative-harm budgets are encoded as closed admissibility conditions inside \(\mathsf A_q\), \(\mathsf G_e\), and \(r_e\).
8. The destination target \(\Theta\) is compact.
9. The hybrid state \(y=(q,z,\ell)\) is fully available to the meta-policy at each review.
10. The meta-policy class permits arbitrary state-feedback selectors.  
    If implementable measurable or continuous selectors are required, those regularity assumptions must be added separately.

Then:

### 10.1 Compactness

For every \(n\ge 0\),

\[
\mathsf T^{II}_n
\]

is compact, and

\[
\mathsf T^{II}_n\subseteq \mathsf T^{II}_{n+1}.
\]

### 10.2 Finite-horizon characterization

A hybrid state \(y\in \mathsf T^{II}_n\) if and only if there exists a causal meta-policy that, against every admissible disturbance sequence, keeps the hybrid execution inside \(\mathsf A\), respects identity continuity and cumulative-harm budgets, and reaches \(\Theta\) in at most \(n\) review decisions.

### 10.3 Reach–avoid–maintain

If

\[
y_0=(q_0,z_0,\ell_0)\in \mathsf T^{II}_N,
\]

then there exists a meta-policy \(\Pi\) such that, for every admissible disturbance strategy \(\delta\in\Delta^{II}\), the hybrid execution:

1. avoids \(F_{\mathrm{forbid}}\) and \(F_{\mathrm{irr}}\);
2. remains inside the authorized transition region \(\mathsf A\);
3. satisfies non-relaxable constraints;
4. satisfies authorized temporary relaxation rules and transition-debt limits;
5. respects identity continuity at every architecture transition;
6. respects cumulative-harm budgets;
7. reaches some destination state

\[
(q^*,z^*,\ell^*)\in\Theta
\]

in at most \(N\) review decisions;
8. after reaching \(\Theta\), maintains the destination typed constraints using the destination Operator I policy.

Thus \(y_0\) is transformationally viable within the registered architecture class over the declared finite transformation horizon.

### 10.4 Complete registered basin under bounded depth

If every registered admissible transformation path requires at most \(N\) review decisions, then

\[
\mathsf T^{II}_N
\]

is the complete registered transformation basin.

In particular, if the architecture graph is acyclic and the total number of possible architecture transitions and pre-transition review steps is bounded by \(N\), then \(\mathsf T^{II}_N\) gives the full transformation basin over the registered graph.

---

# 11. Proof sketch

## 11.1 Compactness preservation

Let \(C\subseteq \mathsf A\) be compact.

### Within-architecture predecessor

For architecture \(q\), define

\[
R_q(C)
=
\left\{
y_q\in \mathsf A_q:
\exists u\in U_q\ \forall w\in W_q,\ 
f_q(y_q,u,w)\in C
\right\}.
\]

Consider the relation

\[
\mathcal R_q(C)
=
\left\{
(y_q,u)\in \mathsf A_q\times U_q:
\forall w\in W_q,\ f_q(y_q,u,w)\in C
\right\}.
\]

Because \(C\) is closed, \(f_q\) is continuous, and \(W_q\) is compact, \(\mathcal R_q(C)\) is closed in the compact space \(\mathsf A_q\times U_q\). Therefore \(\mathcal R_q(C)\) is compact. Its projection onto \(\mathsf A_q\) is \(R_q(C)\), so \(R_q(C)\) is compact.

### Transition predecessor

For edge \(e=(q,q')\), define

\[
R_e(C)
=
\left\{
y_q\in \mathsf G_e:
\exists v\in V_e\ \forall w\in W_e,\ 
r_e(y_q,v,w)\in C
\right\}.
\]

The same argument applies. Define

\[
\mathcal R_e(C)
=
\left\{
(y_q,v)\in \mathsf G_e\times V_e:
\forall w\in W_e,\ r_e(y_q,v,w)\in C
\right\}.
\]

Since \(\mathsf G_e\) is closed in compact \(\mathsf A_q\), it is compact. Since \(r_e\) is continuous and \(C\) is closed, \(\mathcal R_e(C)\) is closed in compact \(\mathsf G_e\times V_e\). Its projection \(R_e(C)\) is compact.

### Union

There are finitely many architectures and edges. Hence

\[
\mathsf B(C)
=
C
\cup
\bigcup_q \{q\}\times R_q(C)
\cup
\bigcup_e \{q\}\times R_e(C)
\]

is a finite union of compact sets and is therefore compact.

Since \(\mathsf T^{II}_0=\Theta\) is compact, induction proves that every \(\mathsf T^{II}_n\) is compact.

---

## 11.2 Monotonicity

If \(C\subseteq D\), then any action that sends all disturbances into \(C\) also sends them into \(D\). Therefore

\[
\mathsf B(C)\subseteq \mathsf B(D).
\]

Since

\[
\mathsf T^{II}_1=\mathsf B(\Theta)\supseteq \Theta=\mathsf T^{II}_0,
\]

induction gives

\[
\mathsf T^{II}_n\subseteq \mathsf T^{II}_{n+1}.
\]

---

## 11.3 Finite-horizon policy equivalence

We prove by induction that \(y\in \mathsf T^{II}_n\) iff a meta-policy can reach \(\Theta\) in at most \(n\) steps while remaining inside \(\mathsf A\).

### Base case

For \(n=0\),

\[
\mathsf T^{II}_0=\Theta.
\]

Thus the system is already at a destination viability kernel. Zero transformation steps are required.

### Induction step

Suppose the claim holds for \(n\).

If

\[
y\in \mathsf T^{II}_{n+1}
=
\mathsf B(\mathsf T^{II}_n),
\]

then either:

1. \(y\in \mathsf T^{II}_n\), in which case the induction hypothesis supplies a policy reaching \(\Theta\) in at most \(n\) steps;
2. there exists a within-architecture action \(u\) such that every disturbance successor lies in \(\mathsf T^{II}_n\);
3. there exists an authorized transition edge \(e\) and action \(v\) such that every transition-disturbance successor lies in \(\mathsf T^{II}_n\).

In cases 2 and 3, the meta-policy uses the witnessing action or transition at the first step. After the disturbance is realized, the successor state lies in \(\mathsf T^{II}_n\). By the induction hypothesis, there is a causal continuation that reaches \(\Theta\) in at most \(n\) further steps. Concatenating gives a policy reaching \(\Theta\) in at most \(n+1\) steps.

Conversely, suppose a meta-policy reaches \(\Theta\) in at most \(n+1\) steps from \(y\). If it reaches immediately, \(y\in\Theta\subseteq \mathsf T^{II}_{n+1}\). Otherwise, its first decision is either a within-architecture action or an authorized transition. Because the policy must be robust against all disturbances, every possible successor must admit a continuation reaching \(\Theta\) in at most \(n\) steps. By the induction hypothesis, every successor lies in \(\mathsf T^{II}_n\). Therefore \(y\in \mathsf B(\mathsf T^{II}_n)=\mathsf T^{II}_{n+1}\).

This proves the finite-horizon characterization.

---

## 11.4 Destination maintenance

By definition of \(\Theta\), every destination state satisfies

\[
z^*\in
\operatorname{RViab}_{\mathcal A_{q^*}}(K_{q^*}^*,T_{q^*}').
\]

Therefore, after reaching \(\Theta\), the destination Operator I policy maintains the typed constraints for the destination horizon.

Concatenating the transformation-reaching meta-policy with the destination Operator I policy gives a complete reach–avoid–maintain strategy.

---

# 12. Recommended status

The result should be classified as:

\[
\boxed{\text{Conditional theorem}}
\]

It is a theorem under the explicit compactness, continuity, full-information, finite-horizon, and selector assumptions. It is conditional because those assumptions are not established for every intended sustainability application.

It should not be presented as:

- a general continuous-time hybrid transformation theorem;
- a delayed hybrid theorem;
- a partial-observation theorem;
- a theorem about unknown architectures;
- a normative theorem selecting the correct destination;
- a universal transformation existence result.

---

# 13. Counterexamples if assumptions are weakened

## 13.1 Discontinuous reset destroys closedness

Let \(Q=\{q,q'\}\), with target

\[
\Theta=\{(q',0)\}.
\]

Let \(Y_q=Y_{q'}=[0,1]\). Let there be one transition edge \(e:q\to q'\) with reset map

\[
r_e(z)=
\begin{cases}
0, & z>0,\\
1, & z=0.
\end{cases}
\]

For every \(z>0\), the system can transform to the target. But at \(z=0\), the reset goes to \(1\), not the target.

The transformation basin contains \((0,1]\) but not \(0\), so it is not closed. Compactness of the predecessor fails. This shows why continuous reset maps, closed-graph reset correspondences, or Hausdorff-continuous exact reachable sets are needed.

---

## 13.2 Outer semicontinuity is not enough

If the reset map is set-valued and merely outer semicontinuous, new unsafe successor states can appear at a limit point. This is the same geometry as the Article 002 outer-semicontinuity counterexample for hybrid ODE tubes.

For Operator II, this means that a sequence of transformable states can converge to a non-transformable state if a grazing transition guard or reset branch suddenly introduces a forbidden successor.

Hausdorff continuity, or lower stability plus closedness, is needed for a clean compact predecessor.

---

## 13.3 Swapping quantifiers breaks robustness

Suppose a transition has two possible disturbance outcomes:

\[
w_1\mapsto \text{destination kernel},
\]

\[
w_2\mapsto \text{forbidden state}.
\]

If the meta-policy could choose the transition action after observing \(w\), transformation would be possible. But Operator II requires

\[
\exists v\ \forall w.
\]

If no single transition action is safe for both \(w_1\) and \(w_2\), the state is not transformationally viable.

This is the Operator II analogue of the common-action and hidden-mode obstructions in the epistemic kernel.

---

## 13.4 Omitting cumulative harm permits burden accumulation

Suppose each transition individually appears admissible, but each adds a small harm \(\ell_g\). Without the cumulative harm coordinate \(\ell\), the predecessor may accept infinitely many or repeatedly harmful transitions.

With

\[
\ell\in\Lambda=\prod_g[0,\bar\ell_g],
\]

and with \(\ell\) updated by \(f_q\) and \(r_e\), any successor exceeding \(\bar\ell_g\) leaves \(\mathsf A_q\) and is rejected.

Thus cumulative harm must be a state coordinate, not a post hoc commentary.

---

## 13.5 Omitting identity continuity permits false transformation

A destination architecture may be viable while violating the protected higher-order identity \(I^H\). For example:

- a forest transforms to a plantation with viable timber output;
- a public service transforms to a privately rationed service with viable fiscal metrics;
- an ecosystem loses a protected functional group but retains aggregate productivity.

Without the predicate

\[
\mathsf{Id}_e,
\]

the theorem would count such paths as successful transformations. The architecture requires identity continuity to be checked at each transition.

---

## 13.6 Unbounded transitions or Zeno executions

If the architecture graph has cycles and no bound on the number of transitions or review steps, the increasing sequence

\[
\mathsf T^{II}_n
\]

may fail to stabilize or may have a non-closed union. In continuous time, unbounded architecture transitions can also create Zeno phenomena.

Therefore the clean theorem uses a finite horizon \(N\), a finite graph, or a bounded transition budget. Extensions require separate non-Zeno, dwell-time, or fixed-point closure assumptions.

---

# 14. Relation to the master manuscript

This theorem gives a precise restricted version of the master manuscript’s Operator II.

The manuscript says that a transformation must:

1. avoid forbidden states;
2. respect transition constraints;
3. reach a destination viability kernel;
4. maintain viability thereafter;
5. satisfy identity continuity and normative procedure.

The draft theorem formalizes these as:

| Manuscript requirement | Formal object |
|---|---|
| architecture graph | \(\mathcal G_A=(Q,E_A)\) |
| reset/translation maps | \(r_e\) |
| forbidden states | exclusion from \(\mathsf A_q\) |
| transition region | \(\mathsf A_q\) |
| identity continuity | \(\mathsf{Id}_e\) |
| cumulative harm | \(\ell\in\Lambda\) |
| destination viability | \(\Theta\) using Operator I kernels |
| reach–avoid–maintain | backward operator \(\mathsf B\) and policy concatenation |
| transformationally viable status | membership in \(\mathsf T^{II}_N\) |

The official system-level statuses can now be given sharper meanings.

---

## 15. Official status map with Operator II

Let

\[
\mathcal K_q
=
\operatorname{RViab}_{\mathcal A_q}(K_q^*,T)
\]

be the current architecture’s robust kernel.

Let

\[
\mathcal C_q
\]

be the within-architecture recovery capture basin under an authorized emergency envelope.

Let

\[
\mathsf T^{II}_N
\]

be the registered finite-horizon transformation basin.

Then the official assessment map becomes:

\[
\mathfrak A_\Omega(q_0,z_0,\ell_0)
=
\begin{cases}
\text{currently viable}, 
& (q_0,z_0,\ell_0)\in \mathcal K_{q_0},\\[2mm]
\text{recoverable within architecture},
& (q_0,z_0,\ell_0)\notin \mathcal K_{q_0}
\text{ but }
(q_0,z_0,\ell_0)\in \mathcal C_{q_0},\\[2mm]
\text{transformationally viable},
& (q_0,z_0,\ell_0)\notin \mathcal C_{q_0}
\text{ but }
(q_0,z_0,\ell_0)\in \mathsf T^{II}_N,\\[2mm]
\text{infeasible within known architectures},
& \text{all registered Operator I and Operator II paths fail},\\[2mm]
\text{indeterminate},
& \text{registry incomplete or proof obligations undischargeable}.
\end{cases}
\]

This preserves the crucial distinction between:

- no known transformation;
- no transformation in a bounded registered class;
- universal impossibility;
- indeterminacy from unrepresented architectures.

The theorem only establishes the third status relative to the registered architecture class.

# 16. Selector regularity

The theorem as stated allows arbitrary state-feedback selectors. This is consistent with the choice-theoretic style of several Article 002 kernels.

For implementable policies, add a separate corollary.

## Corollary: measurable implementation

Assume additionally that:

1. all spaces are standard Borel or compact metric;
2. all maps \(f_q\) and \(r_e\) are Borel measurable;
3. the witness correspondences

\[
y\mapsto
\{u\in U_q:\forall w,\ f_q(y,u,w)\in C\}
\]

and

\[
y\mapsto
\{v\in V_e:\forall w,\ r_e(y,v,w)\in C\}
\]

have nonempty closed values and are measurable;
4. a measurable selection theorem applies.

Then the transformation policy can be chosen measurably.

Continuous selectors require stronger assumptions and should not be asserted without proof.

Recommended status:

\[
\boxed{\text{Conditional corollary}}
\]

# 17. Extension paths

## 17.1 Partial observation

Replace the hybrid state \(y\) by an information state \(i\) in a compact information space \(I\). Then:

- transition guards must be information-measurable;
- identity continuity must be certifiable from the information state;
- cumulative harm budgets must be recursively estimable;
- common-action obstructions may appear.

This connects Operator II to the Abstract Predecessor Schema and the Article 002 information-state kernel.

The theorem becomes conditional on the existence of a compact exact information process and continuous exact update/tube maps.

---

## 17.2 Continuous-time hybrid transformation

Replace the sampled map \(f_q\) by exact tube and endpoint maps:

\[
\mathscr T_q(y,u,w)\subseteq Y_q,
\]

\[
g_q(y,u,w)\in Y_q.
\]

Require:

\[
\mathscr T_q(y,u,w)\subseteq \mathsf A_q
\]

for all inter-sample times.

If \(\mathscr T_q\) and \(g_q\) are Hausdorff-continuous, the same backward operator closes. If only outer semicontinuity is available, the theorem can fail.

This connects Operator II to the Article 002 bounded-jump hybrid ODE kernel.

---

## 17.3 Cyclic architecture graphs

For cyclic graphs and unbounded horizons, define

\[
\mathsf T^{II}_\infty
=
\bigcup_{n=0}^{\infty}
\mathsf T^{II}_n.
\]

This is the least fixed point of \(\mathsf B\) in the sense of increasing iteration, but its closedness and compactness are not guaranteed.

A general infinite-horizon transformation theorem would require one of:

1. finite-state discreteness;
2. continuity of \(\mathsf B\) with respect to increasing unions;
3. closure and compactness of the union;
4. a viability/capture tangency condition;
5. transfinite fixed-point construction;
6. explicit dwell-time/non-Zeno assumptions.

This remains an open extension.

---

## 17.4 Strategic and probabilistic transformation

If transitions depend on strategic actors, the transition predicate becomes something like:

\[
v\in \operatorname{Eq}(V_e,\Theta_e).
\]

If transitions are probabilistic, the target condition may become:

\[
\Pr(\text{reach }\Theta)\ge 1-\epsilon.
\]

These should be treated as different contract modalities:

- deterministic;
- robust;
- probabilistic;
- strategic;
- scenario-only.

The theorem above is the deterministic/robust modality.

---

# 18. What this theorem deliberately does not do

It does not:

1. select the normatively correct destination;
2. prove that transformation is possible when the current kernel is empty;
3. cover unknown or unregistered architectures;
4. guarantee computational tractability;
5. solve delayed hybrid transformation in full generality;
6. prove that identity continuity is preserved by any specific reset map;
7. prove that cumulative harm is correctly measured;
8. replace domain-specific transition models;
9. convert “no known transformation” into universal impossibility.

These limitations should be stated explicitly in the manuscript.
