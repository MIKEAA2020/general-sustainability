# Restricted Composition Theorem (Priority 4)

Below is a draft of a **restricted but nontrivial compositional sustainability theorem**, targeted at the review packet's Priority 4 and §8.4, and discharging the master manuscript's Box 10 (Compositional Sustainability Conjecture) and Box 11 (Proof obligation — sound composition). It is deliberately stated so that the conclusion is *not* a restatement of the assumptions: local invariance plus a checkable gain condition yields global invariance plus a quantitative robustness margin.

---

## 1. What "stronger than tautological" means here

The review packet rejects theorems of the form *"if every assumption and guarantee holds, then the composition is safe."* That is the trivial assume–guarantee discharge. A nontrivial composition theorem must instead:

1. take as input only **local** objects (each module's own invariant set, barrier margin, output bound, and interface sensitivity);
2. impose a **checkable algebraic condition** on the coupling gains that can be verified module-by-module without simulating the coupled system;
3. conclude **global** robust controlled invariance of the product, together with a **quantitative disturbance budget** the composition can absorb;
4. predict **when composition fails** (destruction) and **when coupling creates viability** (rescue), matching the two canonical examples the packet requires.

The small-gain condition below is a **row-sum (∞-norm) diagonal-dominance** condition. This is essential: Article 001 Theorem 11.4 already refutes spectral-radius bounds for cascades via a nilpotent chain (`ρ(M)=0` with unbounded propagation). The row-sum condition is the valid checkable substitute (Article 001 Theorem 11.3), and the theorem states explicitly that spectral radius alone is insufficient.

## 2. Setup and canonical notation

To avoid the notation collisions flagged in the review packet (Error B1), the composition layer uses the following reserved symbols.

| Symbol | Meaning |
|---|---|
| \(i,j \in \{1,\dots,n\}\) | module indices |
| \(x_i \in X_i\) | module-\(i\) state (metric space) |
| \(Q_i \subseteq X_i\) | module-\(i\) local robust invariant set |
| \(b_i:X_i\to\mathbb R\) | module-\(i\) barrier, \(Q_i=\{b_i\ge0\}\) |
| \(u_i \in U_i(x_i)\) | module-\(i\) control |
| \(d_i \in D_i\) | module-\(i\) disturbance |
| \(y_i=h_i(x_i)\) | module-\(i\) interface output |
| \(z_i\) | coupling input to module \(i\) |
| \(\eta_i\) | local barrier margin |
| \(L_i\) | barrier sensitivity to coupling |
| \(Y_j\) | output bound of module \(j\) over \(Q_j\) |
| \(G_{ij}\) | gain from module \(j\) output to module \(i\) input |
| \(M\) | normalized gain matrix |
| \(c,\,C_C,\,L_C\) | commons state, capacity, aggregate load |

Each module is a controlled system

\[
\dot x_i \in F_i(x_i,u_i,z_i,d_i),
\qquad u_i\in U_i(x_i),\ d_i\in D_i,
\]

with coupling input \(z_i\) generated by other modules' outputs. The local safe set is

\[
Q_i=\{x_i\in X_i:b_i(x_i)\ge0\}.
\]

## 3. Local hypotheses (module-by-module, checkable)

**Hypothesis H1 (local robust invariance).** For each \(i\), \(Q_i\) is a robust controlled-invariant set for the *uncoupled* module \(z_i=0\): there exists a causal policy \(\pi_i\in\mathbb P_i^{\mathrm{impl}}\) such that for every \(d_i\in D_i\), trajectories from \(Q_i\) remain in \(Q_i\).

**Hypothesis H2 (strict barrier margin).** On the boundary, the best local control leaves a strict inward margin uniformly:

\[
\eta_i
:=
\inf_{x_i\in\partial Q_i}
\ \sup_{u_i\in U_i(x_i)}
\ \inf_{d_i\in D_i}
D^+ b_i\bigl(x_i;\,F_i(x_i,u_i,0,d_i)\bigr)
\;>\;0.
\]

Here \(D^+b_i\) is the upper-right Dini derivative along the module vector field. This is the quantitative version of Article 001's barrier sufficiency (Theorem 5.1), made strict.

**Hypothesis H3 (interface sensitivity).** The coupling input degrades the barrier derivative at most linearly: there exists \(L_i\ge0\) such that for all \(x_i\in\partial Q_i\), \(u_i\), \(d_i\), and coupling inputs \(z_i\),

\[
D^+b_i(x_i;F_i(x_i,u_i,z_i,d_i))
\;\ge\;
D^+b_i(x_i;F_i(x_i,u_i,0,d_i))
\;-\;L_i\,\|z_i\|.
\]

**Hypothesis H4 (bounded outputs).** Each module's interface output is bounded over its local invariant set:

\[
Y_j:=\sup_{x_j\in Q_j}\|h_j(x_j)\|<\infty.
\]

**Hypothesis H5 (linear coupling bound).** The coupling input to module \(i\) is bounded by a weighted sum of other modules' outputs:

\[
\|z_i\|\;\le\;\sum_{j\ne i}\|G_{ij}\|\,\|y_j\|,
\]

with known gain coefficients \(\|G_{ij}\|\ge0\). (Nonlinear couplings are admitted by taking \(\|G_{ij}\|\) as a local Lipschitz bound over \(Q_j\); see §7.)

These five hypotheses are **local**: each can be verified on module \(i\) alone, using only \(Q_i\), \(b_i\), \(U_i\), \(D_i\), and the interface maps.

## 4. The restricted composition theorem

Define the **normalized gain matrix** \(M\in\mathbb R^{n\times n}\) by

\[
M_{ij}
:=
\begin{cases}
\dfrac{L_i\,\|G_{ij}\|\,Y_j}{\eta_i}, & j\ne i,\\[2mm]
0, & j=i.
\end{cases}
\]

The entry \(M_{ij}\) is the fraction of module \(i\)'s barrier margin that can be consumed by module \(j\)'s maximally excited output.

### Theorem 4.1 (Restricted compositional viability via barrier small-gain)

Assume H1–H5. Suppose the **row-sum small-gain condition** holds:

\[
\boxed{\qquad
\sum_{j\ne i} M_{ij}
\;=\;
\frac{1}{\eta_i}\sum_{j\ne i}L_i\,\|G_{ij}\|\,Y_j
\;\le\;
\rho_i
\;<\;1
\qquad\text{for every }i.
\qquad}
\tag{SG}
\]

Then:

**(a) Global invariance.** The product set

\[
Q:=\prod_{i=1}^n Q_i
\]

is robust controlled-invariant for the coupled system: there exists a causal product policy \(\pi=(\pi_1,\dots,\pi_n)\in\prod_i\mathbb P_i^{\mathrm{impl}}\) such that for every coupled disturbance \(\delta=(d_1,\dots,d_n)\in\prod_i D_i\), every trajectory starting in \(Q\) remains in \(Q\) for all \(t\ge0\).

**(b) Quantitative robustness margin.** The composition absorbs any additional exogenous disturbance \(w_i\) entering module \(i\)'s barrier derivative provided

\[
\|w_i\|\;\le\;\eta_i\,(1-\rho_i).
\]

Equivalently, the product set remains invariant under the enlarged disturbance class as long as the residual margin \(\eta_i(1-\rho_i)\) is not exhausted.

**(c) Contraction under weakened coupling.** If the actual gains satisfy \(\|G_{ij}\|\le\theta\,\|G_{ij}\|_{\max}\) for a common coupling-strength parameter \(\theta\ge0\), then the product set is invariant for every

\[
\theta\;<\;\theta^*
:=
\left(\max_i\sum_{j\ne i}\frac{L_i\,\|G_{ij}\|_{\max}\,Y_j}{\eta_i}\right)^{-1}.
\]

This gives an explicit **coupling-strength threshold** \(\theta^*\) beyond which the theorem no longer certifies invariance.

### Proof sketch

For each \(i\), fix the local robust policy \(\pi_i\) from H1 and evaluate the barrier derivative on \(\partial Q_i\) under the coupled input. By H3 and H5,

\[
D^+b_i
\;\ge\;
\underbrace{D^+b_i(x_i;\pi_i,0,d_i)}_{\ge\,\eta_i\text{ by H2}}
\;-\;
L_i\|z_i\|
\;\ge\;
\eta_i
\;-\;
L_i\sum_{j\ne i}\|G_{ij}\|\,Y_j.
\]

The last inequality uses \(x_j\in Q_j\Rightarrow\|y_j\|\le Y_j\). By the row-sum condition (SG),

\[
D^+b_i
\;\ge\;
\eta_i\left(1-\sum_{j\ne i}M_{ij}\right)
\;\ge\;
\eta_i(1-\rho_i)
\;>\;0
\]

on \(\partial Q_i\), for every admissible coupled disturbance. Hence the vector field points strictly into \(Q_i\) on its boundary, simultaneously for all \(i\). Nagumo's tangent-cone theorem (Article 001 Theorem 5.1, Aubin 1991) applied to the product gives robust controlled invariance of \(Q\). Part (b) follows because an additional disturbance \(w_i\) reduces the margin by at most \(\|w_i\|\), leaving \(D^+b_i\ge0\) whenever \(\|w_i\|\le\eta_i(1-\rho_i)\). Part (c) is the same bound with gains scaled by \(\theta\); solving \(\theta\cdot(\text{row sum})<1\) yields \(\theta^*\). ∎

**Why this is nontrivial.** The conclusion (global invariance plus a disturbance budget) is derived from local data via a checkable algebraic inequality. One can verify H1–H5 and (SG) module-by-module and then conclude composition without simulating the coupled system. Violating (SG) does not merely remove the certificate; §6 shows it coincides with genuine destruction.

### Remark 4.1 (row-sum, not spectral radius)

Condition (SG) is a row-sum / ∞-norm condition. It must not be replaced by \(\rho(M)<1\). Article 001 Theorem 11.4 constructs a nilpotent gain matrix with \(\rho(M)=0<1\) but arbitrarily large cascade propagation, so spectral radius alone does not certify composition. The row-sum condition is the valid sufficient condition (Article 001 Theorem 11.3). This is the precise point where a naive small-gain theorem would be false.

## 5. Commons extension (shared source/sink)

The product structure \(Q=\prod_i Q_i\) is insufficient when modules share a source or sink, because the commons constraint couples all modules through an aggregate budget rather than pairwise interfaces. This is the master manuscript's commons node (\(L_C\le C_C\)).

Model the commons as an additional module \(i=0\) with state \(c\) (remaining capacity or stock), safe set \(Q_0=\{c\ge c_{\min}\}\), barrier \(b_0(c)=c-c_{\min}\), and dynamics

\[
\dot c
=
R(c)-\sum_{i=1}^n \ell_i(x_i),
\]

where \(R(c)\) is regeneration and \(\ell_i(x_i)\ge0\) is module \(i\)'s load. The commons couples to every module and every module couples to the commons.

### Corollary 5.1 (Commons-aware composition)

Augment the gain matrix to include module \(0\). Suppose, in addition to H1–H5 and (SG) for \(i=1,\dots,n\):

**(C1) aggregate load feasibility over the product:**

\[
\sup_{x\in\prod_i Q_i}\sum_{i=1}^n\ell_i(x_i)
\;\le\;
R_{\min}:=\inf_{c\ge c_{\min}}R(c);
\]

**(C2) commons barrier margin dominates the worst residual drawdown:**

\[
\eta_0
:=
\inf_{c\ge c_{\min}}
\left[
R(c)-\sup_{x\in\prod_i Q_i}\sum_i\ell_i(x_i)
\right]
\;>\;0;
\]

**(C3) the commons-to-module feedback gains** \(G_{i0}\) (how capacity \(c\) affects module \(i\)) satisfy the row-sum bound for \(i=1,\dots,n\) including the \(j=0\) term.

Then the enlarged product

\[
Q_0\times\prod_{i=1}^n Q_i
\]

is robust controlled-invariant.

### Proof sketch

Condition (C1)–(C2) give a strict positive margin \(\eta_0>0\) for the commons barrier on \(\{c=c_{\min}\}\), so \(c\) cannot cross below \(c_{\min}\). The commons is then just module \(0\) in the small-gain network, and (C3) folds its feedback into the row-sum condition. Applying Theorem 4.1 to the augmented \((n+1)\)-module network gives invariance of the enlarged product. ∎

**Interpretation.** This formalizes the master manuscript's requirement that aggregate capacity and actor-level allocation both appear: (C1) is the aggregate feasibility of the allocation, and Theorem 4.1's per-module row-sum condition disciplines the individual loads. A module can be locally viable yet compositionally inadmissible if its load, combined with others', violates (C1) or (C2). This is the free-rider case: individual contribution is not pivotal, but aggregate burden exceeds capacity.

## 6. The required destruction counterexample

The packet requires a destruction counterexample. Article 001's MSY counterexample (Counterexample 10.1) is exactly this, and it corresponds to violation of the small-gain condition.

### Counterexample 6.1 (Coupling destroys factorwise viability)

Take two logistic patches with cooperative diffusion \(d>0\), carrying capacities \(C_1\ne C_2\), and harvest floors set at each patch's isolated MSY, \(H_{\min,i}=r_iC_i/4\). Each isolated patch has a nonempty kernel \([C_i/2,\infty)\). Yet the coupled kernel is empty.

**Mechanism in small-gain terms.** At the MSY operating point, each patch's barrier margin \(\eta_i\) vanishes (MSY is the point where the growth curve is tangent to the harvest floor, so the inward margin on the stock face is zero). With \(\eta_i=0\), every normalized gain \(M_{ij}=L_i\|G_{ij}\|Y_j/\eta_i\) is unbounded, and the row-sum condition (SG) fails maximally. The diffusion coupling \(d(S_j-S_i)\) then pushes at least one patch below its MSY stock, where growth cannot meet the floor, and the stock collapses.

**Sharpness.** Article 001 Remark 10.1 shows this is a jump discontinuity in the coupling strength: at \(d=0\) the product kernel is nonempty; for every \(d>0\) with \(C_1\ne C_2\) it is empty. Thus an arbitrarily small coupling destroys viability that the factors individually enjoyed. This is precisely the regime where (SG) has no margin (\(\rho_i\to1\)).

This counterexample shows the small-gain condition is not vacuous: it fails exactly when composition fails.

## 7. The required coupling-rescue example

The packet requires a rescue example where coupling creates viability absent in a factor. Article 001 Example 10.1 supplies it.

### Example 7.1 (Coupling creates viability)

Take \(g_i(s)=s(1-s)\) and diffusion \(d=0.2\). Choose harvest floors derived from the coupled equilibrium \((S_1^*,S_2^*)=(0.5,0.8)\):

\[
H_{\min,1}=0.31,\qquad H_{\min,2}=0.10.
\]

Patch 1 in isolation has \(\max_s g_1(s)=0.25<0.31=H_{\min,1}\), so patch 1 is **not** viable alone. Yet the coupled system has the equilibrium \((0.5,0.8)\), so the coupled kernel is nonempty (subject to sink constraints).

**Mechanism in small-gain terms.** Diffusion from patch 2 (higher stock) into patch 1 subsidizes patch 1's growth, effectively raising its barrier margin \(\eta_1\) above zero. In the augmented network, the gain \(G_{12}\) enters patch 1's barrier derivative with a sign that *adds* inward flow rather than subtracting it. The small-gain condition, applied to the cooperative/monotone coupling, is satisfied because the cross-gain is beneficial. Composition creates viability.

**Monotone structure.** This rescue is an instance of Article 001 Theorem 10.1 (upper-set structure for cooperative fields): when the coupling is cooperative and the target is an upper set, the viability kernel is an upper set, and a super-equilibrium (Remark 10.2) certifies nonemptiness. The small-gain theorem and the monotone upper-set theorem are complementary: the former handles general signed gains via margins; the latter handles cooperative gains via order.

## 8. What the theorem does not claim

To preserve claim-status discipline:

1. **Not universal.** The theorem is a sufficient condition under H1–H5 and (SG). Failure of (SG) removes the certificate but does not by itself prove the composed kernel is empty, except in the specific zero-margin MSY geometry of Counterexample 6.1.
2. **Not a spectral-radius result.** Any attempt to weaken (SG) to \(\rho(M)<1\) is refuted by Article 001 Theorem 11.4.
3. **Not a nonlinear-gain global result.** H5 uses gains as Lipschitz bounds over the local sets \(Q_j\). Strongly nonlinear or threshold couplings require re-verifying the bounds on each region, or a piecewise application.
4. **Not a distributed-parameter or PDE result.** Spatial transport, trade, and leakage are excluded (Article 002 research programme on spatial closure).
5. **Not a strategic/game-theoretic composition.** The theorem composes *controlled* modules under a coordinated product policy. Strategic modules require the strategic contract modality of the master manuscript (Box 10) and are not covered.
6. **Does not compute the kernel.** It certifies that a given product of local kernels is invariant; it does not compute the largest composed kernel, which may be larger (rescue) or smaller (destruction) than the product.

Recommended status:

\[
\boxed{\text{Conditional theorem}}
\]

It is a theorem under the explicit hypotheses H1–H5, (SG), and (C1)–(C3); it is conditional because those hypotheses are not established for every intended sustainability application.

## 9. Downstream consequences

**For the master manuscript.** This discharges Box 11's proof obligation for one restricted class and converts Box 10's Compositional Sustainability Conjecture into: (i) a proved restricted theorem (barrier small-gain + commons), (ii) a destruction counterexample, (iii) a rescue example, and (iv) an explicit open conjecture for the general case. The conjecture statement should be updated to cite this restricted result as the verified subclass.

**For Article 001.** The theorem unifies three existing pieces: the compositional viability theorem (Thm 16.1), the row-sum cascade containment (Thm 11.3), and the spectral-radius negative result (Thm 11.4). It shows that Thm 16.1's input-tolerance condition is a special case of the barrier small-gain condition with the row-sum structure made explicit.

**For Article 002.** The sampled analogue (predecessor-based composition) is a natural extension: replace the barrier margin \(\eta_i\) by the sampled predecessor's one-step tube-safety margin, and the row-sum condition by a discrete gain condition. This connects to the Abstract Predecessor Schema drafted earlier (Priority 1/2) and should be stated as a companion result, not merged.

**For the error docket.** This addresses Priority 4 and §8.4 directly. It does not touch the Article 001 error items A1–A11, which remain separate.

**For publication.** Under the minimum-paper and publication-merit criteria, this theorem belongs in the flagship or a technical supplement, not a separate paper, unless developed with: (a) the sampled/discrete analogue, (b) a worked end-to-end domain composition (groundwater or phosphorus), or (c) the strategic contract modality. Any of those additions could justify a companion.

## 10. Confidence and unresolved questions

**Confidence.** High for the continuous-time barrier small-gain theorem under H1–H5 and (SG): the proof is a direct Nagumo/barrier argument with a row-sum bound, and the counterexamples are inherited from Article 001's verified results. High for the commons corollary under (C1)–(C3).

**Unresolved.**
1. Whether the row-sum condition can be relaxed to a less conservative gain condition (e.g., a genuinely nonlinear small-gain theorem à la Jiang–Teel–Praly) without re-introducing the spectral-radius failure. This is open.
2. The sampled/discrete predecessor version and its exact relation to the continuous barrier version (a bridge theorem is needed; they are not automatically equivalent).
3. Composition under **strategic** modules (equilibrium contracts) — the theorem assumes a coordinated product policy, not a Nash equilibrium of module policies.
4. Handling **threshold/nonlinear** commons (e.g., \(L_C\) with a tipping point) where the linear aggregate bound (C1) is insufficient.
5. Whether the rescue phenomenon can be *characterized* (not just exemplified) by a sign condition on the gains, giving a necessary-and-sufficient criterion for cooperative coupling.
