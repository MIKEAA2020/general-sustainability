## What was actually verified

Eight release assets matched byte counts and provider SHA-256 digests. Five standalone PDFs were text-extracted. The three ZIPs were indexed for research documents; selected passages and artifacts were inspected. The 512 indexed research-text entries (367 distinct hashes) are **not** a count of fully reviewed papers.

The included checks verify synthetic target-specific bounds/witnesses, a constant-history cap criterion, the full account derivative identity, capacity-weighted leakage cancellation, a paired-support illustration, and reaggregated archived score/retention flags. They do not refit the archived models, regenerate Monte Carlo truths, validate ecological data or establish registration timing. New integrated C12 budgets and delay/history simulations remain proposed work.

## Reproduce the bounded checks

No dependencies beyond Python 3 are required for this script:

```bash
# Algebraic checks only, written to a new output file:
python VERIFY_TRANSFER_CHECKS.py --out my_algebra_checks.json

# Include stored artifact reaggregation after downloading the exact release ZIP:
python VERIFY_TRANSFER_CHECKS.py \
  --release-zip /path/to/workspace-edwards.framework.2nd.zip \
  --out my_release_checks.json
```

The ZIP is in the [edwards-framework-e1 release](https://github.com/MIKEAA2020/general-sustainability/releases/tag/edwards-framework-e1). Its required SHA-256 is `3de14e2086ff4f92144882e4f60cae249d18f7f48af07410a0fc207a869d8922`; the script checks this before reading stored artifacts. Original release ZIPs, PDFs, source text and credentials are not redistributed here.
