# Historical creation scripts — F09

These scripts record the executed source-acquisition and package-creation operations. They are not the default reproduction entry points and contain the original workspace/cache paths. Creating F09 from F08 requires F08 and the source cache, and refuses to overwrite an existing F09. Use `src/build_F09.sh`, the test suite and `src/verify_companion_sources_F09.py` for current technical reproduction. Raw copyrighted source documents/text are intentionally excluded.
