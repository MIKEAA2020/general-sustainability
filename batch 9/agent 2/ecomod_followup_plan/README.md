# ECOMOD empirical follow-up: implementation plan

Start with [the implementation plan](FOLLOWUP_IMPLEMENTATION_PLAN_20261029.md).

## Proposed design

Combine two aims in a nested study: estimate trends in defined ecological assets, then test aggregate–asset divergence and its relationship to documented land conversion. Use a forest–cropland core; retain soil, wetland and fisheries as conditional modules rather than promise four complete annual global series.

## Files

- `FOLLOWUP_IMPLEMENTATION_PLAN_20261029.md`: research questions, source checks, estimands, uncertainty, work packages, decision gates and outputs.
- `DATA_REQUIREMENTS_20261029.csv`: 16 input requirements, verified/pending status, spatial/temporal support and use restrictions.
- `artifact_manifest.json`: SHA-256/byte counts of the other package files.

This is a planning deliverable, not a completed novelty review, raw-data download, statistical analysis, calibration or evidence of an observed ecological trend. No new empirical dataset is redistributed in this package. Dataset licences, download details and eligibility rules must be checked at the pilot/data-freeze stage.
