## What each request deliberately does *not* ask for

- No request asks a provider to re-estimate or narrow an uncertainty. R1 and R2 ask for the
  **implementation or design information**, so a precision can be computed or the absence recorded.
- No request asks for exact plot coordinates: R1 specifies **±10 km rounded**, which is sufficient for
  plot→inventory-domain aggregation and stays inside NFI's confidentiality rules.
- No request assumes a source is unavailable because a download failed here. Each states the access
  attempt and its outcome separately from any claim about the file.
- Every request states the non-commercial academic use, credit, no-redistribution of point records, and
  derived-aggregates-only output.
