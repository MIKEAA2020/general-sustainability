# STYLE DIRECTIVE v3 — Formal register: distinct banned categories (2026-09-17)

Supersedes v2 (archived `STYLE_DIRECTIVE_GEMINI_TONE_FORMAL_V2_20260917.md`).
Owner correction 2026-09-17: **over-hedging and internal dialogue are two
distinct things; neither belongs in manuscripts.** The banned classes,
each separately defined, are:

**A. Diary / navigation / geography** — sentences about where material sits
or why it is placed there: "moved here…", "carried verbatim", "one case
requires emphasis", "this section…", "A scope element is relevant to…",
"The results comprise two findings", "The X organizes the results".
Cross-references that are *content* ("reported in the companion framework
paper", "recorded in the Methods section") are permitted; sentences about
the manuscript's own assembly are not.

**B. References to older/superseded manuscript versions** — named or
implied ("the earlier draft", "v50's phrasing", "since corrected"). Never
name a superseded version; if a prior claim has genuine methodological
value, restate it as fact, without its history.

**C. Strawman / phantom framings** — imagined-objection constructions,
defensive openings ("One context warning…", "It may be thought that…"),
denials of positions nobody advanced.

**D. Editorial / self-praise / self-commentary** — quality judgments about
the paper itself ("the mechanism is visible in the record", "clearly",
"honestly", "plainly", "a cleaner sentence"), chat-register informality
("coin flip", "bank account", "as a gift", "wearing a gauge", "rails").

**E. Project-management jargon** — frozen/ledger/firewall/W1/W2/CL-… IDs,
audit paths, rejected-material lists, runner/checkpoint/push notes,
"registered prospectively" (as process language; scientific registration
statements in Methods style are allowed).

**F. Over-hedging** — hedges that are not warranted by the evidence class:
approximators around exact frozen values ("approximately 86 kt" where 86 is
the archived figure), double qualifiers ("perhaps arguably"), scope
weakening without cause, vague temporal hedges. A hedge is kept only where
the underlying value itself is rounded ("approximately 97%" where the
source is "~97%").

**G. Internal dialogue** — sentences to ourselves about the work: "stated
once", "noted here", "the paper discloses", "stated here, at first use",
"as the audits surfaced", decomposition-announcements like "Constructively,"
used as first-person process voice, meta-conditions ("The rule-version
comparison is stated once:"). State the content; never narrate handling it.

**H.(content rule, unchanged) Migration-notes** — which file a table comes
from, typesetting instructions, assembly plans: changelog layer only.

Standing policy (unchanged): Gemini prose mechanics (accessible topic
sentences, numbered content moves, short declaratives) stay; all numerals
must be frozen-archive values; new versions only, never overwrite; F1 v26 is
the live base; E1 frozen v50; E3 frozen v16. Current manuscript carriers:
E1 v55, E3 v20 (both clean under A–G; automated pattern scan = zero hits).
