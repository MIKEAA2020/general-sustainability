## 1. The mismatch

The statement reads:

> "…and an aggregation `π : C([−τ,0], ℝⁿ) → Y` (the declared observable of the history; e.g. restriction to a window, or a finite set of functionals), the aggregate carries a closed autonomous dynamics on `Y` **iff** `f` is constant on the fibres of the truncated-history projection `π̃_τ̃` …"

The proof's (⟹) direction concludes: "with `π` a **restriction-type observable**, unpacking gives … (For general observable functionals, the same argument with the sigma-algebra generated by the aggregate history; **the window case is the declared class — scope-locked**.)"

So the "iff" is asserted for a class that includes "a finite set of functionals", but proved only for window restrictions. The parenthetical "the same argument" is not carried out, and it is not true in general.

**Why it fails for general observables.** Take `τ = 1`, `τ̃ = 0.5`, and two histories that agree on `[−0.5, 0]` and differ on `[−1, −0.5]`:

```
φ_a(s) = 0 everywhere;      φ_b(s) = 0 on [−0.5, 0],  1 on [−1, −0.5).
```

- **Window observable** `f(φ) = φ(−τ̃)`: `f(φ_a) = f(φ_b) = 0`. Constant on fibres of `π̃_{0.5}` ✓ — memory horizon `0.5 < τ`, genuine reduction.
- **Full-window functional** `f(φ) = ∫_{−τ}^{0} φ(s) ds`: `f(φ_a) = 0`, `f(φ_b) ≈ 0.49998`. **Not** constant on those fibres.

And no smaller window rescues it: for every `τ̃ ∈ {0.9, 0.75, 0.6, 0.5, 0.25}` the same pair of histories agrees on `[−τ̃, 0]` while the integrals differ. So the integral observable's memory horizon is exactly `τ` — **no reduction at all**, which is the file's own "honest negative reading", but it is a fact about that observable, not a consequence of the theorem as stated.

## 2. `C-f.Thm1` repaired

> ### C-f.Thm1 (repaired) — RFDE-aggregate memory, window observables
>
> Let `ẋ(t) = f(x_t)` with `x_t ∈ C([−τ,0], ℝⁿ)`, `f` of class `C¹` and Lipschitz on bounded sets. Let the observable be a **window restriction** `π̃_{τ̃} : φ ↦ φ|_{[−τ̃,0]}` for some `τ̃ ∈ (0, τ]`, and let `Y = C([−τ̃,0], ℝⁿ)`. Then the following are equivalent:
>
> **(i)** the aggregate carries a **closed autonomous dynamics** on `Y` — the `Y`-evolution of any solution depends only on its own `Y`-history;
>
> **(ii)** `f` is constant on the fibres of `π̃_{τ̃}`, i.e. `f(φ) = f(ψ)` whenever `φ|_{[−τ̃,0]} = ψ|_{[−τ̃,0]}`, equivalently `f = f̃ ∘ π̃_{τ̃}` for some `f̃ : Y → ℝⁿ`.
>
> The **memory horizon** of the module is the minimal such `τ̃`. It satisfies `τ̃ < τ` exactly when truncation below `τ` loses no `f`-relevant information.

*Proof.* (ii) ⟹ (i): with `f = f̃ ∘ π̃_{τ̃}`, the solution satisfies `ẋ(t) = f̃(x_t|_{[−τ̃,0]})`, which is an RFDE of delay `τ̃` on `Y`. Its evolution depends only on the `Y`-history, by construction.

(i) ⟹ (ii): suppose the `Y`-evolution is autonomous, so there is a map `G` with `ẏ(t) = G(y_t)` for the aggregate `y(t) = x_t|_{[−τ̃,0]}`. Take `φ, ψ` with `φ|_{[−τ̃,0]} = ψ|_{[−τ̃,0]}`. Run the RFDE from each; the aggregate initial conditions coincide, so by autonomy the aggregate trajectories coincide, hence `ẏ(0)` coincides. But `ẏ(0)` determines `ẋ(0) = f(φ)` (the aggregate derivative at `0` is the right-derivative of the history at `0`, which is `f` of the full history). Therefore `f(φ) = f(ψ)`. ∎

**Open, stated precisely.** For a general observable `π` — in particular for functionals with full-window dependence such as `∫_{−τ}^{0}`, windowed extrema, or moving averages that are not restrictions — the equivalence is **not established**. The obstruction is that the aggregate's "history" is then not a truncation of the physical history, so the argument in (i) ⟹ (ii) has no `τ̃` to factor through; what autonomy gives is measurability of `f(x_t)` with respect to the σ-algebra generated by the aggregate history, which is weaker than fibre-constancy of any truncation. Establishing a memory-horizon characterisation for that class is a genuine open problem, and it is the natural next step beyond this theorem.

**What the repaired theorem still delivers.** It lifts the packet's `B5`/`R06.Lem1` fibre criterion from finite-dimensional projections to the history space, for the governance-relevant class the file names — quota reviews, survey triggers, windowed indicators. That is unchanged, and it is what Paper 2's scale/aggregation chapter consumes.
