# C-a.Thm3 — Zero-One-Law Sharpness: REPAIRED

**Target.** The `C-a.Thm3` section of `batch 2/04_open_problems/CA_EXECUTION.md`, the manifest row `C-a.Thm3` (line 101), and the mirrored statement in `batch 2/04_open_problems/C_TIER_COMPLETIONS.md` §C-a(2).

**This file is a proposal. No repository file has been modified.**

**Disposition.** The "lower bound (arbitrariness)" argument claims that **every** subset of the model lattice arises as the satisfying set of some sentence. That requires the kernel-membership language to separate models, and **it does not**: two distinct successor tables can give identical kernels. The repair replaces "arbitrary" with "arbitrary within the definable Boolean algebra" and characterises exactly which subsets arise. **The substantive content survives intact**: non-monotone definable sentences exist, so no extremal-evaluation shortcut applies to them, and instance-level decidability (Thm2) is unaffected.

**Verification.** `reaudit/verify_a3thm2_cathm3_repair.py`, Part B, 14 assertions, exit 0.

## 1. The defect

The proof states:

> "`Φ_S` … has satisfying set exactly `S` ***provided the language separates the models*** (which it does on the declared class: two instantiations differing in any successor-table entry, safe-set cell, or disturbance element are separated by an atomic claim …)."

The parenthetical is false. The atoms of the language are **kernel-membership** claims `x ∈ Viab`, `x ∈ RViab`, and so on — they read the *kernels*, not the tables. Two different tables can produce the same kernels at every state, and then no sentence of the language distinguishes them.

**Counterexample (verified).** `X_h = {a, b}`, `K = {a, b}`:

| table | `Succ(a)` | `Succ(b)` | `Viab` |
|---|---|---|---|
| `t₁` | `{b}` | `{a, b}` | `{a, b}` |
| `t₂` | `{a, b}` | `{a, b}` | `{a, b}` |

The tables differ, the kernels are identical. So the models are language-indistinguishable, and any subset of the model lattice that contains exactly one of them is **not** definable. "Every subset arises" is false.

**Verified extent of the failure.** On a four-model lattice built from the `t₁`/`t₂` pair crossed with two safe sets, the definable Boolean algebra has **2** elements against `|P(𝕄)| = 16` — **14 of 16 subsets are undefinable**.

## 2. `C-a.Thm3` repaired

> ### C-a.Thm3 (repaired) — Zero-one-law sharpness
>
> Let `𝕄` be the finite model class and let the language be the TCS-1.0 judgment language at fixed data: Boolean combinations of kernel-membership atoms over all eight families and all states.
>
> **(i) Definability, not arbitrariness.** The satisfying sets of sentences are exactly the elements of the Boolean algebra `𝔅` generated by the atoms `{ M : x ∈ Viab^{(f)}(M) }`. Two models `M, M′ ∈ 𝕄` are **language-indistinguishable** iff they agree on every kernel membership, for every family and every state; `𝔅` separates models exactly up to that equivalence. In particular `𝔅` may be strictly smaller than `P(𝕄)`.
>
> **(ii) Sharpness survives.** `𝔅` contains sets that are **neither up-sets nor down-sets** of the data order. For every such set, no extremal-evaluation shortcut exists: deciding the sentence requires instance-level computation, not evaluation at the lattice extremes.
>
> **(iii) Decidability.** Every sentence of the language is decidable at each fixed instantiation (Thm2), definable or not in any stronger sense. The sharpness is exactly that **decidability survives while the zero-one law does not**.

*Proof.* (i) Sentences are Boolean combinations of atoms by definition of the language, so their satisfying sets lie in `𝔅`. Conversely every element of `𝔅` is the satisfying set of some Boolean combination: the atoms generate `𝔅` as a Boolean algebra, and the language is closed under the corresponding connectives. Two models agree on every atom iff no sentence distinguishes them, which is the stated equivalence. The counterexample of §1 shows `𝔅 ⊊ P(𝕄)` is possible.

(ii) The witness instance below is definable and non-monotone; verified on the grid model lattice, where the definable algebra contains a set that is neither an up-set nor a down-set.

(iii) Thm2, unchanged: the atoms are computed by the predecessor recursion in `O(N·G·|U|·|D|)` per atom, and the Boolean structure is evaluated bottom-up. ∎

**What changed, and what did not.** The claim "arbitrary satisfying sets occur" is narrowed to "arbitrary *definable* satisfying sets occur". Everything the theorem was *for* — establishing that the monotone fragment's lattice shortcut does not extend to the full language, and that the correct extension is instance-level decidability — is unchanged, and is now supported rather than asserted.

## 3. The witness instance is correct as recorded

The file's witness — "the kernel is nonempty and strictly smaller than the safe set" (`∅ ≠ Viab ≠ K`) — is definable (`⋁_x (x ∈ Viab)` conjoined with `⋁_x (x ∈ K ∧ x ∉ Viab)`) and genuinely non-monotone. **Verified** on `X = {0,1,2,3,4}` with `Succ(x) = {x−1}` (`0` absorbing), using the correct kernel recursion `W ↦ K ∩ Pre(W)`:

| `K` | `Viab` | nonempty | strict | witness |
|---|---|---|---|---|
| `{2,3,4}` | `∅` | false | true | **false** |
| `{0,2,3,4}` | `{0}` | true | true | **true** |
| `{0,1,2,3,4}` | `X` | true | false | **false** |

False → true → false as `K` grows: the satisfying set is neither an up-set nor a down-set, exactly as the record claims. So the witness needs no repair — only the general "arbitrariness" argument around it did.

## 5. Errors in my own tests

Two, both caught by the checks failing, and both worth recording because they are the kind of mistake this theorem is about.

1. **The kernel recursion.** My first `viab` computed `W ↦ Pre(W)` without intersecting `K`. That map is not decreasing, so it does not converge to the viability kernel; with it, the witness instance came out false at all three safe sets. Correcting to `W ↦ K ∩ Pre(W)` reproduced the recorded false → true → false pattern exactly.
2. **Model-lattice design.** My first attempt at the non-monotonicity check used a lattice on which every atom was trivial, so the definable algebra had two elements and contained no non-monotone set — the check failed for a reason that had nothing to do with the theorem. Splitting the two claims across two purpose-built lattices (one with kernel-indistinguishable tables for B2, one with varying kernels for B3) makes each point cleanly.
