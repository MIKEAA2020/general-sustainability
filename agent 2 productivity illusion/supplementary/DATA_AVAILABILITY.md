# Data and Code Availability Statement

**Manuscript:** Emergent Carrying Capacity, the Biocapacity Ratio, and the Productivity Illusion: Deficit-Driven Collapse in a Delayed Coupled Human–Environment Model

---

## Data

This study is a mathematical and computational analysis and reports **no new empirical dataset**. There is no primary observational data collection. The only empirical inputs are published values used to bound the regeneration lag (`τ_g`), drawn from the National Footprint Accounts and the field studies cited in the manuscript References (Poorter et al. 2016; Poeplau et al. 2011; Hutchings & Reynolds 2004; Neubauer et al. 2013; Borucke et al. 2013; Wackernagel et al. 2002). These are not reproduced or re-distributed here; readers should consult those sources for the underlying data.

All numerical results, parameter sweeps, and figures were generated by the accompanying model code run from stated initial conditions and parameters. The **code is the primary artefact**, and its generated outputs are written to `data/topdown_results.json` and `data/r1_r2_sensitivity_results.json`.

## Code and reproducibility

The model is implemented in the `model_sims/` package:

- `corrected.py` — corrected constant-parameter (S0) simulator (deficit-driven stock–flow)
- `topdown.py` — top-down analysis (regimes, ratios `R_B`/`R_A`, flow share, closed forms)
- `char_eq.py` — linearisation coefficients and characteristic-equation roots
- `r1_basin.py` — R1 basin recompute (recover/collapse dichotomy)
- `r1_figure.py`, `r2_figure.py` — render the R1/R2 figures
- `demo`/`mask` computations — see `models.py` (`corrected_s0_summary`, `mask_run`) and manuscript §10
- `_run_topdown.py` — runner that writes `data/topdown_results.json` and the top-down figures
- `_run_sensitivity.py` — ρ-sensitivity sweep
- `numeric_claims.py` — automated verifiers for reported numerical claims

Full step-by-step reproduction instructions are in **`REPRODUCTION_GUIDE.md`** in this package.

## Archival / deposition

The journal policy permits external code deposition. For a formal archival record we recommend depositing this package (the `model_sims/` code, `data/*.json`, the figure-generating scripts, and this supplementary package) in a persistent repository before acceptance, e.g.:

- **Zenodo** (recommended) — DOI-minted archive of the code release; export the git records as a release archive.
- **GitHub** — the working repository is public; a tagged release (e.g. `revision-29`) is the canonical, citable code artefact.

The deterministic model requires no random seed; the reproducibility statement in the manuscript's §8 and `REPRODUCTION_GUIDE.md` specifies the solver, `dt`, history functions, and termination convention for every reported number.

## Third-party content

No third-party data or code is redistributed. The regeneration-lag band values are literature-banded (a qualitative range, not a full digitisation); per-study curve digitisation is explicitly not performed and is declared as pending in the manuscript.
