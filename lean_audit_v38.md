## 2. `prop:ladder` — completed by substitution, on the EBC side

`EBC_Ladder` fixed the *shape*: set survivability stated as

```lean
survivesSetAt I A z0 L := ∃ us, |us| = L ∧ (∀ u ∈ us, inAlphabet u) ∧
                                 ∀ θ ∈ A, survivesTo I θ us z0
```

which is P3's `SurvivableAdm M S k` ("one blind policy keeps every
member alive for k steps") verbatim. With the shapes matching, heredity
is one line, and P3's `VfamAdm_prune_eq` (value = max over the *maximal*
jointly survivable sets) supplies the value formula in the identical
form.

`EBC_Ladder_v2` completed the cardinality facts that formula consumes:

| fact | theorem |
|---|---|
| heredity | `survivesSetAt_mono` |
| at the floor all members agree on `I`, so `M = 1` | `floor_survivable_all_agree` |
| above the edge every pair is Hamming-adjacent, so `M ≤ 2` | `pairs_adjacent_above` |
| no three pairwise-distinct survivors above the edge | `no_three_distinct_above` |
| a surviving subset is a singleton or an adjacent pair | `survivor_is_singleton_or_adjacent_pair` |
| `M = 2` is attained | `adjacent_pair_survives` |
| a subcube with a free coordinate contains an adjacent pair | `subcube_adjacent_pair` |
| a probe, as a restriction of the index set | `inSubcube`, `flip` |

With value `= M/|S|`, that is `1/|S|` at the edge and `min(1, 2/|S|)`
above it: the paper's two rows, `|S|` symbolic, the `2^j` subcube sizes
and the ten numbers left to the verifier.

`pairs_adjacent_above` is where the horizon bound earns its keep:
`far_pair_horizon_bound` caps a distance-`≥2` pair at `10·(z₀−1) ≤ 1`
steps when `z₀ ≤ 1.1`, so no such pair reaches a horizon of two or more.

## 3. The `DetMDP` instantiation — resolved, not left open

The decision rule is the paper's claim, not taste:

| if the paper claims | then |
|---|---|
| type-identity ("is an instance of") | instantiation required for fidelity |
| shape-equivalence ("has the same value form") | shape-sharing suffices |

`prop:ladder`'s proof (`paper2_exact_belief_computation_v10`, ll.
266–282) reads: *"The companion theory's antichain formula **makes** the
kernel value of a prior the maximal survivable-set mass it charges, and
survivability is hereditary downward … so the value at the uniform prior
on a support `S` is `max_{A ⊆ S, A survivable} |A|/|S|`."*

It **applies** the companion formula; it never asserts the ladder *is* an
instance of `VfamAdm`. So the target is shape-equivalence:

**Decision: do not build the `DetMDP` instance.** Supplying a state space
over the sixteen cells, actions, transition/observation data, and a proof
that `survK` reduces to `z ↦ z + drift I u θ` would add mechanism without
adding a theorem. The bridge is recorded as **structural**. Revisit only
if a future edition of the paper claims type-identity.
