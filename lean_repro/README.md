# Reproducible Lean build: exact source bundle and evidence

## What is preserved

`SOURCE_COMMIT.txt` identifies the source commit of `lean/` on `e2-v3-source-year`. Its 67 project files, including 62 `.lean` sources (60 under `Formalizations/`), were fetched from Git blobs and verified byte-for-byte against each blob SHA-1. `source_snapshot.tar.gz` holds those 67 files **plus both executed Lean check sources** (`AxiomFootprint.lean` and `AllFootprints.lean`); `SOURCE_MANIFEST.tsv` covers all **69** files with size, Git blob SHA-1 and SHA-256. `SOURCE_ARCHIVE.sha256` pins the independently preserved, deterministic ~261 KB archive. `verify_inputs.py` compares the archive, manifest and checkout before compilation; it was tested on a separately restored clean source tree. The original Git `lean/` tree remains unchanged.

`evidence/` has actual pinned-toolchain build logs, all 21 named axiom footprints, a **report-only** full environment footprint enumeration, the strict verdict, source scan, and the failed exploratory `native_decide`→`decide` candidate diff/log. A build creates `.olean`/`.ilean` binary intermediates, not new `.lean` manuscript sources; the two generated check `.lean` inputs are preserved in the source archive. Neither compiled binaries nor multi-GB toolchain contents are needed in this workspace.

## What passed and what did not

The exact Lean 4 **v4.34.1** release archive was SHA-256 checked before extraction in `/var/tmp` (outside the saved workspace); `lake build` completed **60/60 jobs**, exit 0. `lake env lean ../lean_repro/AxiomFootprint.lean` returned footprints for all 21 listed manuscript-linked declarations, with only `propext`, `Classical.choice`, `Quot.sound` or no axioms. The comment-aware source scan reported no `sorry`, `admit`, explicit `axiom` or `constant` candidates among 62 `.lean` files. These results are genuine but **not the whole-project clean-axiom verdict**.

A wider report-only `AllFootprints.lean` sweep enumerated **1,973** `Formalizations.*` declarations **reachable through the `Formalizations.lean` aggregate import**. It found **92 unexpected dependency references** across 22 declarations to **10 distinct generated native-decide axioms**, traceable to four `native_decide` tactic uses in `P3_Binomial.lean` and `P3_SupportValue.lean`. The default Lake target does **not** compile three preserved historical modules that the aggregate does not import: `EBC_ExactBelief.lean`, `P1_AssessmentSeparation.lean`, and `P1_AssessmentSeparation_v4.lean` (see `evidence/aggregate_import_inventory.txt`). They are archived source inputs, not covered by this build or environment sweep. It found no `sorryAx`. `check_all_footprints.py` exits **2**: the strict no-unexpected-axiom gate is **BLOCKED**. The 92 references are not 92 independent axioms. Do not silently whitelist them or call the formal layer axiom-free because no explicit `axiom` line or `sorry` appears. A four-occurrence `native_decide`→`decide` scratch candidate failed the build and was **discarded**, not installed or pushed as a proof repair. See `LEAN_BUILD_REPORT_2026-10-01.md` for evidence and scope.

## Reproduce without enlarging the saved workspace

On a machine with ample temporary disk: check out the source commit; verify `SOURCE_ARCHIVE.sha256`, extract the archive into a clean temporary directory, copy `verify_inputs.py` and the manifest/hash files next to it, then run `python3 lean_repro/verify_inputs.py` before generating `.lake` files. Install the exact toolchain specified in `lean/lean-toolchain` outside the workspace and verify the release SHA-256 in the report. From `lean/`, run `lake build`, `lake env lean ../lean_repro/AxiomFootprint.lean` and `lake env lean ../lean_repro/AllFootprints.lean`. Run both Python footprint parsers on their respective saved outputs; expect the current strict parser to **fail**, unless a separately reviewed repair changed the source and was recorded as a new source bundle. Keep hashes, source files, logs and toolchain provenance; do not store `.elan`, `.lake`, `.olean` or compiler downloads in this workspace.
