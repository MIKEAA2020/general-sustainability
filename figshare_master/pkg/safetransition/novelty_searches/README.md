# Related-software search records

Preserved search records supporting the related-software positioning
(Section 5 of the accompanying manuscript) in the same spirit as the
master deposit's novelty searches: the queries behind each positioning
claim are documented, and the returned records (title, URL, verbatim
snippet excerpt, host, rank) are preserved unedited so that the search
is repeatable and the claims auditable.

- Search dates: 2026-09-20 (agent-mediated web search).
- Records are verbatim snapshots trimmed for length; no result was
  added, reordered, or edited beyond excerpting.
- Mapping to the manuscript:
  - q1 viability-kernel computation landscape (Section 5, first family);
  - q2 exact rational Farkas-certificate practice outside environmental
    modelling (Sections 2.3 and 5; certificate re-verification prior art);
  - q3 composite-indicator and dashboard software (Section 1 and
    Section 5, practice context);
  - q4 exact-verification companions and arbitrary-precision libraries
    (Section 5, verification-deposit pattern; mpmath is arbitrary-
    precision floating point, not exact rational);
  - q5 Fourier-Motzkin implementations (Section 5; pyfme is the nearest
    elimination neighbour, symbolic and general-purpose; none tracks
    Farkas provenance for certificate return);
  - q6 MCDA index software and compensation levels (Section 5, second
    family; the compensation axis the manuscript formalizes).
- The gap statement of Section 5 ("none of these families returns
  certificates; none computes in exact arithmetic") is made against the
  records preserved here.
