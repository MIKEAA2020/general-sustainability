[C-OLD] **Proposition 7 (common-action obstruction under output feedback).** *Suppose no informative observation arrives before the next action must be selected.

[C-OLD] If the compatible common-action set satisfies $\mathcal{U}_{\mathrm{com}}(B) = \bigcap_{x \in B} \mathcal{R}_{\mathcal{V}}(x) = \varnothing$ for the information state $B$, then $B$ is not robustly viable under output feedback — even if every compatible physical state is individually viable under full information.*

[C-OLD] *Proof.* Output feedback must choose one prescription before the uncertainty within $B$ is resolved; by hypothesis no single action is robustly safe for all compatible states.

[C-OLD] This is Theorem 3 restated for the output-feedback policy class; the proof of Theorem 3 applies verbatim.
[C-NEW] Theorem 3 covers the output-feedback form directly: the theorem quantifies over observation-based policies, and an output-feedback policy that must select its action before an informative observation arrives is one of them, so no separate proposition is stated.
