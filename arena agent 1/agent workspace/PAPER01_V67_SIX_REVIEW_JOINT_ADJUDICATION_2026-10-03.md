### A concrete policy-class counterexample (not a counterexample to the correctly restricted theorem)

Let `xdot=u`, `U={−1,+1}`, `V=[−1,1]`, `B={0}`, with no informative observation. At **Δ=3**, either **constant** held action leaves `V` before the review, so `A_tube(B,3)=∅`. But the nonanticipative **time-dependent open-loop** control `+1` on `[2n,2n+1)` and `−1` on `[2n+1,2n+2)` keeps `x(t)∈[0,1]` forever. This proves the final arrow of Proposition 3 is not valid for unrestricted within-review switching. It does **not** defeat a policy model that requires the first action to remain constant for three units. The review's proposed “hold for length **≥Δ**” phrasing should instead use the *specified first* hold duration (or prove the generalization for an exact class); varying class durations change the statement.
