4. The scope finding. Tri has a `hold` value, so the layer's action type
   Nat -> Tri admits partial holds, which the paper's verified alphabet
   (17 actions at m = 4: the 16 cells plus the all-hold) excludes. From
   z0 = 1.0, holding at exactly the coordinate where a pair differs and
   matching elsewhere gives both cells +1/10 and rescues the pair. So
   "survivable exactly from z0 >= 1.1" is true over the paper's alphabet
   and false over the unrestricted one. Sufficiency needs no restriction
   (its witness uses only cell actions); necessity needs it essentially,
   which is why inAlphabet exists. Recommendation: state the action
   alphabet as part of the proposition.
