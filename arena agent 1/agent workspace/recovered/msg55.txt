The DetMDP instantiation is resolved rather than left open, by the
paper's wording. The rule is the paper's claim: type-identity ("is an
instance of") would require it, shape-equivalence ("has the same value
form") would not. prop:ladder's proof (ll. 266-282) says the companion
theory's antichain formula "makes the kernel value of a prior the maximal
survivable-set mass it charges" - it APPLIES the companion formula and
never asserts the ladder is an instance of VfamAdm. So: no DetMDP.
Building one would add mechanism without adding a theorem. Recorded as a
structural bridge, to revisit only if a future edition claims
type-identity.
