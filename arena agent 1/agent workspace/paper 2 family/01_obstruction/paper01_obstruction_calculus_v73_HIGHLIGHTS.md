# Highlights — Paper 01 v73

- **One principle, many certificates.** An observation-based regulator must select a single response for an entire information state; every certificate in the paper proves that the relevant selection set is empty (selector principle, Prop 2.2). The main text is now organised around this idea instead of mechanism by mechanism.
- **Exact where it can be.** Finite systems: backward belief recursion sound and complete, one-step common-action test necessary and sufficient, finite obstruction trees, machine-checked in Lean 4 (33 theorems, no `sorry`). Static observation: exact reduction to open-loop robust viability. Audited hold class: the two certificates are jointly complete on the 48-cell grid.
- **Checkable in continuous time.** Common-action obstruction with Farkas dual and Helly bound (m+1 witness states); delayed-information bound inf q/ε < T_obs with threshold form and an LP whose Farkas dual is the certificate; finite-time exit by comparison; an oracle-recourse certificate for affine systems with an exact planar threshold τ* = 7/50 that is genuinely three-way.
- **Limits of verdicts, not only of policies.** An observation-only safety certifier exists iff safe-set membership is constant on fibres; the certainly-safe set is the sound relaxation; a certainty-equivalence controller on a biased but injective sensor can have an empty kernel.
- **The gap is located, not hidden.** No certificate pair reading only the window sub-model can be complete (four-state witness); the remaining problem is stated with the post-observation recourse verdict as its target.
- **Every certificate names its remedy.** Table 3 pairs each certificate with the response correspondence it empties and the monitoring design change it licenses: separate the incompatible states, observe earlier, grant post-observation authority, refine the index or fall silent, correct the bias.
- **Everything numerical is reproducible exactly.** 30 rational-arithmetic checks (V1–V12) cover every number and every finite instance in the paper.
