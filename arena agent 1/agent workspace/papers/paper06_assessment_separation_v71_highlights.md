# paper06 v71 — Key points (for the submission form; JMCDA has no highlights section)

* Compensatory (weight-adaptive) and noncompensatory (common-plan) acceptance of a transition differ only by quantifier order; at a fixed trajectory the full-cone aggregate is lossless.
* For any finite plan menu the acceptance gap is the part of the convex hull of the plans' required margins that no single plan dominates — the scalarization gap transported to path-wise transition certification; a synchronisation lemma fixes which path protocol the margin geometry describes exactly.
* On an explicit rational datum the gap has nonempty interior; at its canonical point (6/5, 6/5) the scalar margin 12/5 clears 2 while no primitive plan meets both floors, and even the single fixed weight (1,1) accepts a plan that fails a floor.
* Fractional blends close the action-indexed gap exactly but not the shared-shock gap at the canonical point (12/5 < 5/2); full-depth alternation in time never implements a blend.
* Every positive-elasticity CES aggregator falsely certifies an exact interval of gap states (critical floors 1 < 5/4 < √2 < φ < √3 < … → 2); only the Leontief member is uniformly safe.
* Per-floor path minima, the reserve and the acceptance protocol reconstruct the typed verdict; the aggregate alone does not. Aggregation is a claim about which plan is licensed, not a presentation choice.
