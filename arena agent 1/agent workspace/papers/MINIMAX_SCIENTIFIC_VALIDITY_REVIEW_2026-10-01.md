## 3. Hypothesis-tested manuscript findings

### A. `thm:general`: division by zero for an allowed rational product prior — false as stated for *all tree nodes*

The theorem sets `K≥1`, finite disturbance sets, an **arbitrary product measure** `μ*`, partitions ending in singleton paths, finite actions, bounded rational `G`. Its node recursion defines `w(C′)=μ*(C′)/μ*(C)` for every review-tree cell, and claims all node values rational. It never requires positive mass of every cell or restricts the recursion to positive-mass nodes.

Take `K=2`, `D₁={0,1}`, `D₂={0}`, product prior `μ₁=δ₀`, `μ₂=δ₀`, `P₁=P₂={ {(0,0)}, {(1,0)} }`, singleton action sets, and `G≡0`. All data, including probabilities, are **rational** and meet the exact stated finite/filtration hypotheses. At the legal null node `C={(1,0)}` the unique child has `μ(C′)/μ(C)=0/0`, so the *printed recursion for all nodes is undefined*. The expectation/value and obstruction implication remain well-defined **on the support**; this is a missing full-support/positive-cell (or null-node convention) hypothesis, not evidence against the positive-cell DP. The source batteries use positive-weight trees and do not cover this case. Neither this theorem nor its null-cell semantics is formalized in Lean.

### B. The conditional `ess sup` envelope cannot freely re-optimize **past** actions — false under the literal definition, repairs need history state

Definition `def:envelope` says `Q(t)=ess sup_π E[F^π | F_t]` over *all complete nonanticipative policies* and calls its evaluation a Bellman recursion. The finite well-posedness theorem defines its operator only on posterior information cells `b`, with no committed action-prefix in the node. Under the stated finite/rational assumptions, let a controller choose `a₁∈{0,1}` while blind, then reveal an equiprobable hidden bit `s∈{0,1}`; the second action is a singleton dummy; bounded rational terminal margin `G(s,a₁)=1[a₁=s]` (positive safe). Every real policy has unconditional expected value **`1/2`**, so `Q(0)=1/2`. Yet after the reveal, pointwise `ess sup` over *complete* policies can retrospectively choose a different `a₁=s` on each branch, producing **`Q(1)(s)=1` on both**. No precommitted policy realizes that pasted past. A Bellman update based only on posterior cells overestimates the root (`1` versus `1/2`) if it treats that `Q(1)` as the continuation; a state including the realized past action fixes the example. The later `thm:general` *does* index `N_k` by action prefix, precisely the missing distinction. Thus the general finite theorem's backward-induction/identification claim needs an explicit history/Markov-sufficiency restriction, not just rational finite data. The bridge lemma (negative expectation implies positive-measure violations) is unaffected. This unformalized finding does not contradict the recorded small instances, which use correctly committed policy trees.

### C. New live v16 prior-art paragraph identifies local and global emptiness without a horizon argument

The v16 addition says “the common safe-action set is nonempty exactly when the relevant discriminating domain is nonempty,” then reads `thm:dual` as a certificate for the **discriminating kernel** being empty. Under the static theorem's own compact/C¹/affine hypotheses, local tangency and global viability differ: set `V=[0,1]`, `ẋ=1`, `U={0}`, a singleton disturbance and `B={0}`. The active lower facet has inward drift `+1`, so the common *instantaneous* safe-action set at `B` is nonempty; nevertheless **every** initial state in `[0,1]` exits within finite time and the infinite-horizon viability/discriminating kernel (deterministic special case) is empty. If “relevant discriminating domain” means a specifically *local tangency* construction, it must be defined and distinguished from the global descending kernel described in the preceding sentences. This is a **false/unjustified global identification in new prose**, not a counterexample to the static local minimax theorem. It was introduced after upstream v12; no source v12 verifier could check it.
