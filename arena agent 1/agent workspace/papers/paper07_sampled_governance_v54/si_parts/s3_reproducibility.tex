\subsection{Reproduction entry points}

The source bundle README provides command lines and expected outputs. Principal entry points are:
\begin{itemize}
\item \texttt{\detokenize{work/p07_core.py --grid 4001}}: logistic fixed point, local multipliers, crossing scans, the v53 \(\pm2\%\) one-at-a-time sensitivity, and the baseline record; use \texttt{\detokenize{--joint-only --grid 20001}} for the full 128-corner rerun;
\item \texttt{\detokenize{src/p7_empirical/ram_crosssection.py}} and \texttt{\detokenize{src/p7_empirical/tr_ranked_test.py}}: stock-level spectra and the \(\Tr\)-ranked test; run from \texttt{\detokenize{src/p7_empirical/}} so the relative RAM input path resolves;
\item \texttt{\detokenize{work/screen_battery_v53.py}}: screen sensitivity battery; run from \texttt{\detokenize{src/p7_empirical/}};
\item \texttt{\detokenize{work/adh_verify_v53.py}} and \texttt{\detokenize{work/qcal_fplacement_v53.py}}: local ADH, F-placement, and calibration checks using the recovered cohort inputs;
\item \texttt{\detokenize{work/nonlinear_flow_check_v53.py}}: full nonlinear-plant/controller-flow finite-difference check against the local monodromy;
\item \texttt{\detokenize{work/make_figures_v53.py}}: the joint sensitivity figure from the retained full-grid JSON;
\item \texttt{\detokenize{work/make_rho_figure_v53.py}}: the baseline multiplier plot with explicit exponential-update labels;
\item \texttt{\detokenize{work/make_supplement_tables.py}}: per-stock, case, power, comparator, and F-placement LaTeX tables.
\end{itemize}
Exact working directories, dependency versions, seeds, and stdout/log files are retained in the source bundle rather than inferred from this list.

\subsection{Local ADH and fishing-mortality verification}

Recovered cohort inputs resolved a previous missing-file issue. The ADH script was rerun locally against the recovered files. Recomputed ADH values agree with deposited values to numerical precision, and archived descriptives and cohort/group summaries reproduce. A fresh 20,000-draw seed-11 resampling run placed 2.33\% of broader-pool median draws below the archived cohort median of 1.7902 buffer-years; the archived run gives 2.12\%. This checks the resampling calculation and shows a similar tail fraction, not a calibrated probability that any fishery is unsustainable.

The F-calibration and placement script reproduces the 42-stock screen cohort. For 43 intersected stocks, fisheries-ADH \(F\) agrees with last-\(F\) for 42; \texttt{\detokenize{SPRBLKGSA29}} is the exception. For the broader pool of 454 stocks, the F quartiles and all 13 taxonomic-group quartiles match the archived summaries. Among 38 screen-cohort stocks with F series, the mean of stock-level F medians is 0.3663 (IQR 0.2701--0.7243); broader-pool \(F_{\rm now}\) has median 0.2143 (IQR 0.0800--0.4639). These are descriptive calibration and placement checks, not proof that F or an ADH buffer is a valid proxy for institutional pressure.
