## Source-specific changes and boundaries

1. **§3.7, oracle recourse (main and S1):** The formerly general control-affine statement is narrowed to branch/scenario-wise affine-in-state **and** affine-in-input dynamics with coefficients independent of the controlled path, affine safety facets, and policy-independent exogenous admissible disturbance scenarios. In this class variation of constants gives the displayed kernel identity **exactly**; the supplementary proof no longer relies on an unbounded first-order remainder. If `inf_d Γ_h<0`, a *single* scenario with negative bracket exists without infimum attainment and is admissible against every policy. The failing stored branch may depend on the policy, not every branch must fail. The old state-dependent `B(x)=x` witness is excluded by an explicitly load-bearing condition. The existing linear double-integrator three-branch example remains within the narrower class. General state-dependent input coefficients/nonlinear facets require a separately proved one-sided remainder bound and are **not** certified by this proposition.
2. **§3.3/§9, delayed observation:** (H3.2) still defaults to **all** implementable measurable blind-window controls, with the original unconditional nonviability conclusion for that full class. A separately declared institutional restriction now yields only **class-relative** nonviability. The 48-cell hidden-regime grid, its counts `42 = 30 + 12`, and both figure/table legends explicitly use an action held for the *whole* blind window. With unrestricted per-step switching, there are 30 nonviable cells, and alternating `+1,-1,…` rescues the 12 hold-only cells. The hold-class integer safe-step count is `floor(z0−1)`; for integer review deadlines the viability test `z0≥1+Tobs` remains exact. The continuous interpolated crossing quantity `z0−1` is not mislabeled an integer step count. Both the main and repeated supplementary timing theorem/remark distinguish the two policy classes.
3. **§10, deterministic-kernel proposition:** It now assumes the set-valued model and the fixed-kernel stochastic model share a single deterministic successor per state/action, deterministic observation, the same absorbing unsafe state, matching admissible action class, and `B=supp(b)⊆V`. Posterior support then equals `Post`, and a **horizon/pathwise** argument (not a first-step claim) gives `B∉W_k ⇒ V_k(b)≤1−min_B b<1`. The phrase “adversarial within support” was removed from this fixed-stochastic-value claim: a support-only 99/100 safe, 1/100 unsafe kernel is not a deterministic kernel and does not satisfy the new hypothesis. No undefined robust/minimax value has been silently substituted. The supplementary held-class grid has been renamed `V^hold` and explicitly separated from the unrestricted `V_k`; its half-mass deficit is a class-relative calculation, not a direct instance of the unrestricted proposition. The finite-action two-floor example remains a direct deterministic-kernel instance.
4. **§3.3 LP example and S1 Helly proof:** The decaying system `z⁺=(9/10)z±u` retains its valid polytope LP threshold `(10/9)^K`; the unbounded gap is explicitly a *different*, non-decaying `z⁺=z±u`, `z0=2` system, comparing a whole-window two-action **hold** class with a polytope-per-step relaxation. The general held safe-step count is `floor(z0−1)`, not an unqualified real-valued discrete survival time; unrestricted finite per-step switching also rescues this gap example. The supplementary Helly proof now establishes exactly the main `C¹`, `q≥0`, active-facet tangent condition `∇q·f≥0` for control-affine dynamics. Its safe-control sets are intersections of closed halfspaces with convex `U(x)`; it no longer incorrectly demands convex `q` or proves a different discrete `q(F)≤0` theorem.
