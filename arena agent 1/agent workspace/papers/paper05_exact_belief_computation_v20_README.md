## Compilation
Both `.tex` files search `./`, `figs/` and `paper05_exact_belief_computation_v20_src/figs/`, so they compile unchanged in the repository folder and in a flat working folder. Compiled with Tectonic 0.15.0 (XeTeX engine); one 0.8 pt overfull box in the main text (Table 2) and one 3.3 pt box in the SI (Lean name list); all cross-references resolve; the SI's main-text numbers are checked against the compiled `.aux` (check TXT.2); the compiled numbering of every result quoted in captions and in the SI is checked (TXT.1).

## Environment used
Linux x86_64, Python 3.13, NumPy 2.x (bit-mask census and alpha-sets), SciPy 1.17 (only for the floating-point LP of Section 8, which is the object of study there), Matplotlib 3.10 (figures). The full pipeline (`run_all.py`) takes 793 s; the verification 310 s (full) or 10 s (`--quick`).
