## 2. The three misalignments — evidence and fixes (v68 → v69)

### (a) The CQSP 2007 "no loss of value / equality of value functions" attribution — UNVERIFIABLE AS STATED; re-scoped

v68 stated, at three main-text sites and one supplement site, that Cardaliaguet, Quincampoix, and Saint-Pierre (2007) "absorb[s] imperfect information into an estimation space … **with no loss of value**" / "pass … **with equality of value functions** and a Dini-derivative characterization". Verification attempt (2026-10-03): the chapter's own abstract (link.springer.com/chapter/10.1007/978-0-8176-4553-3_1, accessed via the S2 API record and the Springer page) describes "a survey of results for differential games obtained through Viability Theory … basic theory for differential games (obtained in the 1990s) … recent advances in … games with hard constraints, stochastic differential games, and hybrid differential games … several applications" — **no imperfect-information/estimation-space no-loss claim appears in the accessible record**; the open-access Dauphine copy is currently unresolvable from this environment. The v67 flag therefore stands: a survey listing alone does not establish the claimed no-loss theorem.

**Fix (four sites).** The estimation-tube claims now say: CQSP (2007) *survey* the viability approach to differential games — viability and discriminating kernels for games with hard constraints, with value characterizations in Dini-derivative form (this much is verifiable from the abstract and is the school's core toolkit); the estimation-space reduction itself is presented under the set-membership semantics of **Kurzhanski and Vályi (1997)** (already in both bibliographies); and every value-coincidence statement is now conditional: "**where that reduction applies with matching policy and admissibility hypotheses it is exact for values, and those hypotheses are not automatic**". This matches the supplement's own already-correct hedge ("Where the cited estimation-space reduction applies with matching policy and admissibility hypotheses, it returns the verdict; without those hypotheses the reduction is not a separate proof") and the S2(b) worked comparison, both of which stand unchanged.

Sites: main §1.1 (line 130), §5(b) (1423), §6.3 (1493); supplement S2(b) (705–714).

### (b) The DeepReach "six-dimensional grid reference / roughly four fifths" figure — NOT IN THE SOURCE; replaced with the verified facts

v68's §1.3 claimed that "in one benchmark against a six-dimensional grid reference, a neural backward reach–avoid tube recovers roughly four fifths of the true unsafe set" (Bansal and Tomlin, 2021). Verification against the full text (arXiv:2011.02082v2, downloaded and searched 2026-10-03): **the paper contains no six-dimensional grid reference and no four-fifths figure.** Its grid-referenced benchmark is the *three-dimensional* pursuit–evasion game (relative coordinates, Level Set Toolbox 101³ grid), reporting "The BRT volume error for DeepReach is 0.43%"; the six-dimensional joint-space instance "is intractable to solve directly through a principled PDE solver and thus cannot be directly compared with DeepReach" and is validated "only by projection back to relative coordinates" (MSE 2.1×10⁻⁴); the nine-dimensional three-vehicle instance has no reference at all.

**Fix (one site).** The sentence now reports the verified facts, which carry the same argumentative point more honestly — neural solvers purchase scalability with approximation *and with loss of a reference to check against*: "their grid-referenced benchmark, a three-dimensional pursuit–evasion game, reports a 0.43% backward-reachable-tube volume error against the grid solution, and at six dimensions and above, where such methods are needed, no grid reference exists at all: the six-dimensional instance is validated only by projection back to relative coordinates."

Site: main §1.3 (lines 266–270).

### (c) The main-text §5(c) erosion statement vs. the supplement's own hypothesis-scoped version — ALIGNED

v68's main §5(c) asserted, as a general fact with a loose attribution — "output feedback of the estimate preserves safety on a buffered subset (observer-to-viability transfer with safety buffer; Sontag, 1998), and eroded kernels remain invariant under bounded estimation and implementation errors (erosion absorbs the error)" — while the supplement's expanded S2(c) **explicitly declines** the universal form: "the robust-input radius ρ, the admissibility condition and the invariant set must be established for the particular plant; **no universal erosion coefficient or no-loss theorem is asserted here**."

**Fix (one site).** Main §5(c) now matches the supplement: the buffer transfer is "the classical observer-to-control separation idea (Sontag, 1998) — provided the buffered set has been proved invariant under the resulting input perturbations, the feedback's Lipschitz constant and the observer's error bound jointly covering the perturbation. No universal erosion coefficient or no-loss theorem holds without such a per-plant premise; the precise condition is in Supplementary Material, S2." Sontag (1998) is retained only for what the textbook supports (observer-based output feedback and separation-type results), not as the source of a viability-erosion theorem.

Site: main §5(c) (line 1425).
