## What changed, in the requested order

1. **Theorem 3 and supplement proof.** H3.1 now requires a branch-independent record before the blind deadline for *every* compatible safe realization under a fixed control history, rather than merely the existence of some indistinguishable branches. H3.2 takes a compact, safe post-observation cell, a positive-width strip `0 <= q <= a` with `a > max_B0 q`, a rate `epsilon>0`, and, **for every implementable blind control** in the declared class, a genuine compatible minimizer/disturbance solution that persists through first contact and has actual derivative `d q/dt <= -epsilon` almost everywhere on the closed strip until strict exit. H3.3 retains `min_B0 q / epsilon < T_obs`. The proof now uses a stopping/continuation argument: if the adverse path stayed nonnegative to any `t1` strictly between that bound and `T_obs`, it could not leave through the upper edge and integration would give `0 <= q(t1) <= min_B0 q - epsilon*t1 < 0`. The argument includes `min q=0`; `f=0` fails the new H3.2 at the boundary. The supplement repeats the **new** theorem and proof instead of v65's positive-only integration. No theorem is claimed for a system lacking a genuine original-system adverse solution.
2. **Theorem 7.** It is now stated for a single post-observation initial cell: a static reading leads to an open-loop control for that cell. The global Nagumo-style boundary test is only an appropriately regular **sufficient** condition for invariance of *all V*, not a necessary condition for viability from an arbitrary smaller `B0`. The proof explicitly gives `xdot=x-1`, `V=[0,2]`, `B0={1}` as the counterexample to the discarded necessity reading. The subsequent characterization no longer calls the global boundary test necessary and sufficient for a given `B0`.
3. **Belief types.** The common ambient domain is all nonempty subsets of X; a general initial **prior** is split by its time-zero reading `B_y=B intersect O^-1(y)` before its first action. An actual post-observation information cell shares an action; an unsplit prior spanning readings need not. Compactness is requested only in theorems that use it. Finite recursion and one-step common-action statements are explicitly for a current single-reading cell, with a separate prior-lift via every nonempty initial cell. Proposition 8's observation-refinement inclusion is on the *same ambient prior domain*, not between differently typed collections of sensor-specific fibres. These changes make the result type-check at the level of declarations; a full policy-measurability/selection proof is still a gate.
4. **Table 3.** The five rows are the actual safe-state fibres for y=2,3,4,5,6. The y=4 fibre `(1,3),(2,2),(3,1)` has no common safe first action although its reading certainly certifies current safety. y=2 is a full-information one-step failure, not an epistemic witness; y=5/6 have explicit history-dependent continuation rules. The finite **discrete** one-step theorem and exact recursion now support those claims rather than the continuous boundary-tangency theorem. [Exhaustive 511-belief fixed-point run](content_audit/paper01_referee_2026-10-02/two_patch_results.txt); [additional witness tests](content_audit/paper01_referee_2026-10-02/check_v66_repair.py).
5. **Table 1 / Prop 5.** The table records the nonempty common admissible set `{0}` and the empty common *safe* set. Prop 5's nonconvex `U(S)={0,S}` remains the original system; controller convexification to `[0,S]` is explicitly a different problem, not a repair to or consequence of the disturbance-only relaxation.

**Downstream checks.** The abstract and conclusion no longer treat classification limits and one-policy failures as general nonviability mechanisms; “undecidable” is replaced by window-data non-determination. The static aggregate-fibre example is now described as a two-variable LP rather than a nontrivial continuum Helly witness. Section 9 is called symbolic, not calibrated. ## The quantifier correction

For robust epistemic viability the logical shape is `exists policy, for every compatible state/disturbance, stays safe`. Its negation is `for every policy, exists a compatible adverse state/disturbance (or an inadmissible selection), violates safety`. **The new H3.2 uses this second shape** after H3.1 has made the policy's blind actions a single history. The suggested stronger condition that *every* admissible trajectory drifts down is sufficient but unnecessary, and would exclude the intended hidden-branch example in which only one branch worsens under each blind action. Likewise, declaring `q=0` unsafe would change the paper's closed safe-set convention `V subset {q>=0}`; the repair instead requires true negative drift **through** `q=0` and original-system continuation to strict `q<0`.

The revised condition is not vacuous: a separate continuous hidden-branch *hold-class* test has `q=x`, `x(0)=1`, hidden `theta in {-1,+1}`, `xdot=theta*u`, constant observation, `u in {-1,+1}` held, and `T_obs=2`. For each held `u`, the adversary's branch `theta=-u` has derivative `-1`, reaches zero at 1 and is strictly negative by 1.5. This is a **mathematical satisfiability check of the revised condition**, not proof that the paper's distinct discrete held-policy grid satisfies its continuous hypotheses. Per-step switching may avoid failure, so the claim is class-specific.
