# Separate figure files — Paper 1 (JEDC submission)

These files are the figures for **"Aggregate Indices and Transition Safety"**,
submitted *separately* from the manuscript source (as the journal requires).
The LaTeX (`paper1_assessment_separation_v39.tex`) still compiles with the
figures referenced from its `figs_p1/` subfolder; these standalone files are
for the submission system's figure uploads.

## Graphical abstract

| File | Format | Size | Notes |
|---|---|---|---|
| `graphical_abstract.pdf` | PDF (vector) | — | **Preferred format**; resolution-independent |
| `graphical_abstract.tif` | TIFF (LZW, 300 dpi) | 2656 × 1062 px | **Preferred format**; 2× the 531×1328 minimum |
| `graphical_abstract.png` | PNG | 2656 × 1062 px | Preview copy |

Aspect ratio 2.5 : 1 (w : h); readable at 5 × 13 cm. Summarizes the article:
two binding floors → the weighted index approves for every weighting → but no
single plan keeps both floors above zero → a reserve stock separates the
impossibility region from the rescue set; convexifying the plan menu closes
the gap, alternating plans does not.
