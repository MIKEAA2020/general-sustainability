\subsection{Check list}
The verification script \path{paper05_exact_belief_computation_v20_verification.py} runs the checks of Table~\ref{tab:S8checks}; the full mode recomputes the six-cube classification, the six-cube clique family by an independent algorithm, the five-cube alpha-sets and the floating-point sweep (about five minutes on one core), the \texttt{--quick} mode reuses the stored stage outputs for the expensive items. Every check is a boolean on exact rational or integer quantities; the final text checks parse the compiled main text and supplement and compare quoted numbers with \texttt{results.json}.
