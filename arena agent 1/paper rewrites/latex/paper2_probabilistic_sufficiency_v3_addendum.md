## 3. Strengthening beyond the menu

- **The audit's own slips, corrected:** (a) "V^seq − V^open-loop is the value of information" is false on this instance — no information arrives inside the blind window, so sequential blind *equals* open-loop (proved in the lattice theorem); the information gap is observed − open-loop, realized on the common-action cells. (b) The audit's "open-loop value is 1 iff z₀ ≥ 2, or k=1 and z₀ ≥ 2, and so on" is replaced by the exact three-regime formula. (c) The general closed forms surface a constraint every prior statement (seed through v2) had only as a "vacuous indicator" placeholder: **the floor constraint at t = 0 (z₀ ≥ 1, value 0 below)** — now stated and verified on z₀ < 1 sweeps.
- **Residual defect the audit missed, found and fixed:** the closed-form derivation's continuation sentence ("the learned law u = θ regenerates the realized branch") is wrong for the θ = −1 branch at large horizons in the plain delayed instance; the rising control u = +1 is what regenerates, and the stabilization proposition pins the frozen value (verified to horizon 40). The D10 probe proof's u = θ is correct (there θ·u = θ² > 0) and is unchanged.
- **Battery discipline held:** three script bugs were caught before shipping (a branch-mass error in the set formula, a drift term ignoring θ·û, a majority-parity error), plus one verifier fix (gap positivity at degenerate priors w ∈ {0,1}); and one build defect (a 136 pt overfull from side-by-side cases displays) was caught by the zero-overfull bar and fixed by stacking. My own "four-valued" claim for the noisy family was corrected to the proved three levels {0, 1−ε, 1} — the wrong-reading path needs *more* height than the correct one, so V = ε is unreachable.
